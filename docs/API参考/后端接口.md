# 后端接口文档

本文档介绍 HS2-Tools 的后端接口（Wails 绑定方法与事件）。

## 接口概览

`wails/app.go` 中 `App` 结构体的导出方法通过 `Bind` 暴露给前端。前端通过 `wails/frontend/src/logic/ipcUtils.ts` 封装层调用：

```typescript
import ipcUtils from '../logic/ipcUtils'

// 调用示例
const mods = await ipcUtils.readPngForMod('/path/to/card.png')
```

ipcUtils 内部调用 Wails 自动生成的绑定（`wails/frontend/wailsjs/go/main/App`）。Go 方法返回的 `error` 会转为前端 Promise 的 reject。

## 文件操作接口

### readPngForMod

从 PNG 文件提取 Mod GUID 列表。

```typescript
ipcUtils.readPngForMod(filePath: string): Promise<string[]>
// Go: func (a *App) ReadPngForMod(path string) ([]string, error)
```

**参数**：
- `filePath` - PNG 文件绝对路径

**返回**：Mod GUID 数组

**示例**：

```typescript
const modIds = await ipcUtils.readPngForMod('C:\\HS2\\UserData\\chara\\female\\card.png')
console.log(modIds) // ['author.mod.v1', 'another.mod.v2']
```

### readAllCharaNames

从 PNG 文件提取角色名称列表。

```typescript
ipcUtils.readAllCharaNames(path: string): Promise<string[]>
// Go: func (a *App) ReadAllCharaNames(path string) ([]string, error)
```

**返回**：角色名称数组（无数据时返回 `['']`）

### readPngForShow

从 PNG 文件提取图像数据（Base64）。

```typescript
ipcUtils.readPngForShow(filePath: string): Promise<string>
```

**返回**：Base64 编码的图像数据

**示例**：

```typescript

<img src={`data:image/png;base64,${imageData}`} />
```

### getAllFiles

递归扫描目录获取文件列表。

```typescript
ipcUtils.getAllFiles(
  path: string,
  options?: Options
): Promise<string[]>
// Go: func (a *App) GetAllFiles(path string, options *scanner.Options) ([]string, error)

interface Options {
  excludeDir?: string[]      // 排除的目录名
  targetExtension?: string[] // 目标扩展名，如 ['.png', '.zipmod']
}
```

**示例**：

```typescript
const files = await ipcUtils.getAllFiles('C:\\HS2\\UserData\\chara\\female', {
  targetExtension: ['.png'],
  excludeDir: ['backup', 'temp']
})
```

## 下载接口

### triggerDownload

触发文件下载。兼容层自动拼接下载目录（`游戏目录/mods/hs2-tool-download`），Go 端自动拼接 BetterRepack 基础 URL。

```typescript
ipcUtils.triggerDownload(info: { name: string; url: string }): Promise<void>
// Go: func (a *App) TriggerDownload(info DownloadModel) error
```

**示例**：

```typescript
await ipcUtils.triggerDownload({
  name: 'author.mod.v1',
  url: 'download/AISHS2/mod.zipmod'
})
```

### cancelDownload

取消指定下载任务。

```typescript
ipcUtils.cancelDownload(guid: string): Promise<boolean>
// Go: func (a *App) CancelDownload(guid string) bool
```

### getDownloaderStatus

获取下载器状态。

```typescript
ipcUtils.getDownloaderStatus(): Promise<DownloaderStatus>
// Go: func (a *App) GetDownloaderStatus() DownloaderStatus

interface DownloaderStatus {
  goDownloaderAvailable: boolean
  goDownloaderPath: string
}
```

### onDownloadProgress

监听下载进度（`download:progress` 事件）。返回取消订阅函数。

```typescript
ipcUtils.onDownloadProgress(
  callback: (event: DownloadProgressEvent) => void
): () => void

type DownloadProgressEvent = {
  guid: string
  type: 'progress' | 'complete' | 'error' | 'info'
  downloaded?: number
  total?: number
  speed?: number
  percent?: number
  path?: string
  message?: string
}
```

**示例**：

```typescript
const unsubscribe = ipcUtils.onDownloadProgress((data) => {
  console.log(`${data.guid}: ${data.percent}%`)
})
// 组件卸载时
unsubscribe()
```

### onDownloadComplete

监听下载完成（`download:complete` 事件）。

```typescript
ipcUtils.onDownloadComplete(
  callback: (event: DownloadCompleteEvent) => void
): () => void

type DownloadCompleteEvent = {
  guid: string
  success: boolean
  message?: string
}
```

## 错误处理

所有绑定调用都可能失败，务必使用 try-catch：

```typescript
try {
  const result = await ipcUtils.readPngForMod(path)
} catch (error) {
  console.error('Backend call failed:', error)
  // 处理错误
}
```
