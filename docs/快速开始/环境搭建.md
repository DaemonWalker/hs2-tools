# 环境搭建

本文档介绍如何搭建 HS2-Tools 的开发环境。

## 系统要求

### 必需软件

| 软件 | 版本 | 用途 |
|------|------|------|
| Go | 1.25+ | 编译 Wails 后端与命令行工具 |
| Node.js | 18+ | 前端构建 |
| npm | 9+ | 前端包管理 |
| Wails CLI | v2.12 | 开发与打包 Wails 应用 |
| Git | 任意 | 版本控制 |

### 操作系统

- **Windows 10/11** - 主要开发与运行平台
- **macOS 10.15+** - 支持（需自行验证）
- **Linux** - 支持（部分功能可能需要调整）

## 安装步骤

### 1. 安装 Go

访问 [Go 官网](https://go.dev/dl/) 下载安装包，或使用包管理器：

```bash
# Windows (使用 winget)
winget install GoLang.Go

# macOS (使用 Homebrew)
brew install go

# Ubuntu/Debian
sudo apt update
sudo apt install golang-go
```

验证安装：

```bash
go version  # go1.25.x 或更高
```

### 2. 安装 Node.js

访问 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本，或使用包管理器：

```bash
# Windows (使用 winget)
winget install OpenJS.NodeJS

# macOS (使用 Homebrew)
brew install node

# Ubuntu/Debian
sudo apt update
sudo apt install nodejs npm
```

验证安装：

```bash
node --version  # v18.x.x 或更高
npm --version   # 9.x.x 或更高
```

### 3. 安装 Wails CLI

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.12.0
```

验证安装：

```bash
wails version  # v2.12.x
```

可运行 `wails doctor` 检查平台依赖是否齐全（如 Windows 需要 WebView2 运行时，Windows 10/11 通常已内置）。

### 4. 克隆项目

```bash
git clone <repository-url>
cd hs2-tools
```

### 5. 安装依赖

```bash
# 根目录依赖（ESLint / Prettier 等）
npm install

# 前端依赖
cd wails/frontend
npm install
```

这将安装：
- React 和 React Router
- Ant Design 组件库
- Zustand 状态管理
- 开发工具（TypeScript、Vite、Tailwind CSS）

## 验证安装

运行以下命令验证环境是否正常：

```bash
# 前端类型检查与构建
cd wails/frontend
npm run build

# 启动开发模式（在项目根目录）
npm run wails:dev
```

## 编译 Go 命令行工具（可选）

`wails/cmd/` 下的命令行工具可独立编译使用（应用本身已内嵌同样的功能，无需额外编译）：

```bash
cd wails

# 编译下载器
go build -ldflags="-s -w" -o build/bin/downloader.exe ./cmd/downloader

# 编译扫描器
go build -ldflags="-s -w" -o build/bin/scanner.exe ./cmd/scanner

# 编译爬虫工具
go build -ldflags="-s -w" -o build/bin/sideloader.exe ./cmd/sideloader
```

### 编译参数说明

| 参数 | 说明 |
|------|------|
| `-ldflags="-s -w"` | 去除符号表和调试信息，减小文件体积 |
| `-o <path>` | 指定输出路径 |

## 常见问题

### 1. 安装依赖时网络超时

**问题**：`npm install` 卡在 `reify: Timing` 或报错 `ECONNRESET`

**解决**：切换 npm 镜像源

```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 或使用其他镜像
npm config set registry https://registry.npmjs.org/
```

### 2. Go 依赖下载失败

**问题**：`go build` 下载模块超时

**解决**：配置 Go 代理

```bash
go env -w GOPROXY=https://goproxy.cn,direct

# 重新拉取依赖
cd wails
go mod tidy
```

### 3. Windows 下 PowerShell 执行策略限制

**问题**：执行 npm 脚本时报错 `无法加载文件，因为在此系统上禁止运行脚本`

**解决**：以管理员身份运行 PowerShell，执行：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 4. 类型检查失败

**问题**：`npm run build` 报错

**解决**：检查 TypeScript 版本是否兼容

```bash
# 查看 TypeScript 版本
cd wails/frontend
npx tsc --version

# 如果是版本问题，可以尝试重新安装
rm -rf node_modules
npm install
```

- **[VSCode](https://code.visualstudio.com/)** - 推荐，配合以下扩展：
  - ESLint
  - Prettier
  - Go
  - TypeScript Importer

`wails dev` 启动的开发窗口支持 WebView DevTools（窗口内右键 → Inspect）调试前端；Go 后端可使用 Delve 调试（参见 [开发指南](./开发指南.md)）。
