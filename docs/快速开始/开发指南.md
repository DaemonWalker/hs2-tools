# 开发指南

本文档介绍 HS2-Tools 的开发流程和调试方法。

## 常用命令

### 开发模式

```bash
# 启动 Wails 开发模式（热重载）
npm run wails:dev
```

`npm run wails:dev`（等价于 `cd wails && wails dev`）会：
1. 启动前端 Vite 开发服务器
2. 编译并启动 Go 应用
3. 监视前端文件变化并热重载
4. 自动重新生成前后端绑定代码（`wails/frontend/wailsjs/`）

### 前端单独开发

```bash
cd wails/frontend

# 启动 Vite 开发服务器
npm run dev

# 前端构建（tsc && vite build）
npm run build
```

### 代码检查

```bash
# 运行 ESLint（根目录）
npm run lint

# 运行 Prettier 格式化（根目录）
npm run format
```

### 构建

```bash
# 构建应用（前端构建 + Go 编译，输出 wails/build/bin/）
npm run wails:build

# 打包 Windows 可执行文件
npm run wails:build:win
```

## 项目配置

### Wails 配置

`wails/wails.json` 定义了 Wails 项目配置：

```json
{
  "name": "hs2-tools",
  "outputfilename": "hs2-tools",
  "frontend:install": "npm install",
  "frontend:build": "npm run build",
  "frontend:dev:watcher": "npm run dev",
  "frontend:dev:serverUrl": "auto"
}
```

### TypeScript 配置

前端配置位于 `wails/frontend/tsconfig.json`（单一配置，`strict` 模式）。

### Vite 配置

`wails/frontend/vite.config.ts` 定义了构建配置：

```typescript
export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@renderer': path.resolve(__dirname, './src'),
      '@shared': path.resolve(__dirname, './src/shared/src'),
      '@wailsjs': path.resolve(__dirname, './wailsjs')
    }
  }
})
```

### 路径别名

| 别名 | 实际路径 |
|------|----------|
| `@renderer` | `wails/frontend/src` |
| `@shared` | `wails/frontend/src/shared/src` |
| `@wailsjs` | `wails/frontend/wailsjs`（Wails 生成的绑定） |

使用示例：

```typescript
// 使用路径别名
import { useSettingStore } from '@renderer/store/settingStore'
import { EXE_NAME } from '@shared/constants'
import { ReadPngForMod } from '@wailsjs/go/main/App'
```

## 开发流程

### 1. 添加新的后端接口

**步骤 1**：在 `wails/app.go` 的 `App` 结构体上添加导出方法

```go
// wails/app.go
func (a *App) MyNewHandler(data string) (string, error) {
    // 处理逻辑（error 会转为前端 Promise 的 reject）
    return result, nil
}
```

**步骤 2**：重新运行 `wails dev`，Wails 自动重新生成绑定代码到 `wails/frontend/wailsjs/go/main/App.d.ts`

**步骤 3**：在 `wails/frontend/src/logic/ipcUtils.ts` 封装兼容接口

```typescript
import { MyNewHandler } from '@wailsjs/go/main/App'

const ipcUtils = {
  // 添加新接口（camelCase 命名，与旧接口风格一致）
  myNewHandler: (data: string): Promise<string> =>
    MyNewHandler(data),
  // ...
}
```

**步骤 4**：在前端使用

```typescript
const result = await ipcUtils.myNewHandler(data)
```

如需异步进度通知，在 Go 方法中用 `wailsRuntime.EventsEmit` 推送事件，并在 `ipcUtils.ts` 中用 `EventsOn`/`EventsOff` 封装监听接口（参见 [../架构设计/进程通信](../架构设计/进程通信.md)）。

### 2. 添加新页面

**步骤 1**：在 `wails/frontend/src/pages/` 创建页面组件

```typescript
// wails/frontend/src/pages/MyPage.tsx
import { FC } from 'react'

export const MyPage: FC = () => {
  return <div>My Page Content</div>
}
```

**步骤 2**：在 `wails/frontend/src/App.tsx` 添加路由

```typescript
import { MyPage } from './pages/MyPage'

function App(): JSX.Element {
  return (
    <Routes>
      <Route path="/my-page" element={<MyPage />} />
    </Routes>
  )
}
```

**步骤 3**：在 Header 添加导航链接（可选）

### 3. 添加新的 Zustand Store

```typescript
// wails/frontend/src/store/myStore.ts
import { create } from 'zustand'

interface MyState {
  data: string
  setData: (data: string) => void
}

export const useMyStore = create<MyState>((set) => ({
  data: '',
  setData: (data) => set({ data })
}))
```

### 4. 添加新的 Go 内部包

1. 在 `wails/internal/` 下创建包目录并实现功能
2. 在 `wails/app.go` 中引用并封装为 `App` 导出方法
3. 如需独立命令行工具，在 `wails/cmd/<工具名>/main.go` 添加入口，复用 internal 包

## 调试技巧

### 调试前端

1. **DevTools**
   - `wails dev` 启动的应用窗口内右键选择「Inspect」打开 DevTools
   - 前端单独开发（`npm run dev`）时直接使用浏览器 DevTools

2. **React DevTools**
   - 安装浏览器扩展，在浏览器开发模式下使用

### 调试 Go 后端

1. **VSCode 调试配置**

Wails 应用是标准 Go 程序，可直接用 Delve 调试。创建 `.vscode/launch.json`：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Debug Wails Backend",
      "type": "go",
      "request": "launch",
      "mode": "debug",
      "program": "${workspaceFolder}/wails"
    }
  ]
}
```

2. **日志输出**

```go
// Go 后端日志（输出到终端）
fmt.Printf("[Backend] Message: %v\n", data)
```

```typescript
// 前端日志 → 转发到 Go 后端终端输出
await ipcUtils.log('debug info', someData)
```

### 调试 Go 命令行工具

1. **独立运行测试**

```bash
cd wails
go run ./cmd/downloader -url "http://example.com/file.zip" -out "test.zip"
```

2. **添加日志输出**

```go
fmt.Printf("[Debug] Variable: %v\n", variable)
```

## 代码规范

### 文件命名

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 组件 | PascalCase | `MyComponent.tsx` |
| 工具函数 | camelCase | `myUtil.ts` |
| Store | camelCase + Store | `myStore.ts` |
| 样式 | camelCase + .css | `myStyle.css` |

### 代码风格

- 使用单引号 `'` 而非双引号 `"`
- 省略分号
- 缩进使用 2 个空格
- 最大行宽 100 字符

### TypeScript 规范

```typescript
// ✅ 显式声明类型
const handleClick = (event: MouseEvent): void => { ... }

// ✅ 使用接口定义对象
interface Props {
  title: string
  onClick: () => void
}

// ❌ 避免使用 any
const data: any  // 不推荐

// ❌ 避免隐式 any
function process(data) { ... }  // 不推荐
```

### React 规范

```typescript
// ✅ 使用函数组件 + FC 类型
import { FC } from 'react'

export const MyComponent: FC<Props> = ({ title, onClick }) => {
  return <div>{title}</div>
}

// ✅ 使用自定义 Hooks 封装逻辑
const useMyData = () => {
  const [data, setData] = useState(null)
  // ...
  return data
}
```

## 性能优化

### 1. 虚拟滚动

对于大量数据列表，使用虚拟滚动或 antd Table 分页。

### 2. 防抖和节流

```typescript
// 搜索输入防抖（300ms）
debounceTimerRef.current = setTimeout(() => {
  setSearchText(value)
}, 300)
```

### 3. 避免重复渲染

```typescript
// ✅ 使用 useMemo 缓存计算
const expensiveValue = useMemo(() => {
  return computeExpensiveValue(data)
}, [data])

// ✅ 使用 useCallback 缓存回调
const handleClick = useCallback(() => {
  doSomething()
}, [])
```

## 故障排除

### 开发服务器无法启动

```bash
# 清除前端缓存
rm -rf wails/frontend/node_modules/.vite

# 重新安装依赖
cd wails/frontend && npm install

# 重新启动
npm run wails:dev
```

### 后端接口调用无响应

1. 检查 `wails/app.go` 中方法是否导出（首字母大写）
2. 检查 `wails dev`/`wails build` 是否重新生成了 `wailsjs` 绑定
3. 检查 `ipcUtils.ts` 中的封装是否正确

### 前端绑定类型报错

1. 删除 `wails/frontend/wailsjs/` 后重新运行 `wails dev` 重新生成
2. 检查 Go 方法签名变更后是否重启了开发模式
