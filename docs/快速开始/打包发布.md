# 打包发布

本文档介绍如何构建和发布 HS2-Tools 应用。

## 构建流程

### 完整构建流程

```
1. 前端构建（wails build 自动执行 wails.json 中的 frontend:build）
   - TypeScript 编译（tsc）
   - Vite 打包 → wails/frontend/dist
2. Go 编译
   - 前端产物通过 //go:embed 嵌入可执行文件
   - 内嵌资源（resources/sideload.zip）一并打包
3. 输出单个可执行文件 → wails/build/bin/
```

### 构建命令

```bash
# 完整构建（输出 wails/build/bin/hs2-tools.exe）
npm run wails:build

# 打包 Windows（amd64）
npm run wails:build:win
```

也可以直接在 `wails/` 目录下使用 Wails CLI：

```bash
cd wails

# 当前平台构建
wails build

# 指定平台
wails build -platform windows/amd64

# 生产模式 + 去除调试信息（Windows GUI 应用无控制台窗口）
wails build -platform windows/amd64 -ldflags "-s -w -H windowsgui"
```

## 配置说明

### Wails 项目配置

`wails/wails.json` 定义了构建配置：

```json
{
  "$schema": "https://wails.io/schemas/config.v2.json",
  "name": "hs2-tools",
  "outputfilename": "hs2-tools",
  "frontend:install": "npm install",
  "frontend:build": "npm run build",
  "frontend:dev:watcher": "npm run dev",
  "frontend:dev:serverUrl": "auto",
  "author": {
    "name": "gcc",
    "email": "215136855@qq.com"
  }
}
```

### 关键配置项

| 配置项 | 说明 |
|--------|------|
| `name` | 项目名称 |
| `outputfilename` | 输出的可执行文件名 |
| `frontend:install` | 构建前安装前端依赖的命令 |
| `frontend:build` | 前端构建命令（构建产物输出到 `frontend/dist`） |
| `frontend:dev:watcher` | 开发模式下的前端热重载命令 |

### 应用信息

应用元数据（名称、图标、版本信息等）位于 `wails/build/` 目录：

```
wails/build/
├── appicon.png          # 应用图标
├── windows/             # Windows 平台资源（icon、manifest、info.json）
├── darwin/              # macOS 平台资源
└── bin/                 # 构建输出目录
```

## 资源文件处理

### 前端产物内嵌

Wails 应用将前端构建产物直接嵌入可执行文件，无需外部资源目录：

```go
// wails/main.go
//go:embed all:frontend/dist
var assets embed.FS
```

### 数据包内嵌

BetterRepack 基础数据包同样内嵌：

```go
// wails/app.go
//go:embed resources/sideload.zip
var sideloadZip embed.FS
```

因此最终分发物是**单个 exe 文件**，用户配置与数据在运行时写入 `os.UserConfigDir()/hs2-tools/`（Windows 即 `%APPDATA%/hs2-tools/`）。

## 平台特定说明

### Windows

**构建要求**：
- Go 1.25+
- Wails CLI v2.12
- Windows 10/11（WebView2 运行时通常已内置）

**输出文件**：
- `wails/build/bin/hs2-tools.exe` - 单个可执行文件，可直接分发

**WebView2 处理**：

Wails Windows 应用依赖 WebView2 运行时。构建时可通过 `-webview2` 标志指定处理方式：

```bash
# 用户未安装 WebView2 时自动下载（推荐）
wails build -webview2 download

# 将 WebView2 引导程序嵌入安装包
wails build -webview2 embed
```

**NSIS 安装程序**（可选）：

```bash
# 需要本机安装 NSIS
wails build -nsis
```

### macOS / Linux

本项目主要面向 Windows 平台（游戏为 Windows 平台），其他平台未验证，需自行调整。

## CI/CD 集成

### GitHub Actions 示例

```yaml
# .github/workflows/build.yml
name: Build and Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.25'

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 18

      - name: Install Wails CLI
        run: go install github.com/wailsapp/wails/v2/cmd/wails@v2.12.0

      - name: Install frontend dependencies
        run: npm install
        working-directory: wails/frontend

      - name: Build application
        run: wails build -platform windows/amd64
        working-directory: wails

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: hs2-tools-windows
          path: wails/build/bin/
```

## 发布检查清单

### 发布前检查

- [ ] 版本号已更新
- [ ] 更新日志已编写
- [ ] 前端构建通过（`cd wails/frontend && npm run build`）
- [ ] 功能测试完成
- [ ] `wails dev` 开发模式验证通过

### 构建后检查

- [ ] 可执行文件可以正常启动
- [ ] 前端页面正常加载（内嵌产物完整）
- [ ] 下载 / 扫描 / 爬虫等核心功能正常
- [ ] 配置文件正确写入 `%APPDATA%/hs2-tools/`
- [ ] 在未安装 WebView2 的环境中验证启动提示（如启用 `-webview2`）

## 版本管理

### 语义化版本

使用 [SemVer](https://semver.org/lang/zh-CN/) 规范：

```
主版本号.次版本号.修订号
```

- **主版本号** - 不兼容的 API 修改
- **次版本号** - 向下兼容的功能新增
- **修订号** - 向下兼容的问题修复

### 版本发布流程

1. 更新版本号

2. 编写更新日志

3. 提交并打标签

```bash
git add .
git commit -m "Release v1.2.0"
git tag v1.2.0
git push origin main --tags
```

4. 构建并发布

```bash
npm run wails:build:win
# 上传 wails/build/bin/ 下的产物到发布页面
```

## 常见问题

### 构建失败：前端产物缺失

**问题**：`go:embed all:frontend/dist` 报错找不到文件

**解决**：先执行前端构建，或直接使用 `wails build`（会自动执行 `frontend:build`）

### Windows Defender 报毒

**问题**：构建的 exe 被 Windows Defender 拦截

**解决**：
1. 添加代码签名证书
2. 向 Microsoft 提交误报申诉
3. 用户添加排除项

### 启动后白屏

**问题**：应用启动后窗口空白

**解决**：
1. 确认 `wails/frontend/dist` 构建产物存在且完整
2. 确认 WebView2 运行时已安装
3. 开发模式（`wails dev`）下用 DevTools 查看控制台错误
