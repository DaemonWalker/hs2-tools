# 主题系统

本文档介绍 HS2-Tools 的主题系统实现。

## 概述

HS2-Tools 支持双主题切换：

| 主题 | 名称 | 特点 |
|------|------|------|
| `modern-dark` | 赛博紫夜 | 深色背景 + 紫蓝渐变 + 毛玻璃效果 |
| `clean-light` | 简洁专业 | 浅色背景 + 清新蓝色 + 简洁风格 |

## 实现方案

使用 **CSS 变量 + data-theme 属性** 实现主题切换：

```
HTML
├── data-theme="modern-dark" 或 "clean-light"
└── CSS 变量根据 data-theme 改变值
```

## 主题配置

### CSS 变量定义

```css
/* src/renderer/src/assets/themes/modern-dark.css */
[data-theme="modern-dark"] {
  /* 背景色 */
  --bg-primary: #0d0d1a;
  --bg-secondary: #1a1a2e;
  --bg-tertiary: #252538;

  /* 强调色 */
  --accent-primary: #a855f7;
  --accent-secondary: #6366f1;

  /* 文字色 */
  --text-primary: #ffffff;
  --text-secondary: #a0a0b0;

  /* 边框 */
  --border-color: rgba(168, 85, 247, 0.2);

  /* Ant Design 覆盖 */
  --ant-primary-color: #a855f7;
  --ant-text-color: #ffffff;
}

/* src/renderer/src/assets/themes/clean-light.css */
[data-theme="clean-light"] {
  /* 背景色 */
  --bg-primary: #f5f7fa;
  --bg-secondary: #ffffff;
  --bg-tertiary: #f0f2f5;

  /* 强调色 */
  --accent-primary: #1677ff;
  --accent-secondary: #4096ff;

  /* 文字色 */
  --text-primary: #1f1f1f;
  --text-secondary: #666666;

  /* 边框 */
  --border-color: #e4e7ed;

  /* Ant Design 覆盖 */
  --ant-primary-color: #1677ff;
  --ant-text-color: #1f1f1f;
}
```

### Ant Design 主题覆盖

```css
/* 确保 Ant Design 组件使用主题色 */
[data-theme="modern-dark"] .ant-typography {
  color: var(--text-primary) !important;
}

[data-theme="modern-dark"] .ant-card {
  background: var(--bg-secondary);
  border-color: var(--border-color);
}

[data-theme="modern-dark"] .ant-btn-primary {
  background: linear-gradient(135deg, var(--accent-primary), var(--accent-secondary));
}
```

## 主题切换

### Store 实现

```typescript
// src/renderer/src/store/themeStore.ts
import { create } from 'zustand'

type Theme = 'modern-dark' | 'clean-light'

interface ThemeState {
  theme: Theme
  setTheme: (theme: Theme) => void
  toggleTheme: () => void
}

const THEME_KEY = 'hs2-tools-theme'

const getStoredTheme = (): Theme => {
  return (localStorage.getItem(THEME_KEY) as Theme) || 'modern-dark'
}

export const useThemeStore = create<ThemeState>((set) => ({
  theme: getStoredTheme(),

  setTheme: (theme) => {
    localStorage.setItem(THEME_KEY, theme)
    document.documentElement.setAttribute('data-theme', theme)
    set({ theme })
  },

  toggleTheme: () => {
    set((state) => {
      const newTheme = state.theme === 'modern-dark' ? 'clean-light' : 'modern-dark'
      localStorage.setItem(THEME_KEY, newTheme)
      document.documentElement.setAttribute('data-theme', newTheme)
      return { theme: newTheme }
    })
  }
}))
```

### 主题切换组件

```typescript
// src/renderer/src/components/app/ThemeSwitcher.tsx
import { FC } from 'react'
import { Button, Tooltip } from 'antd'
import { MoonOutlined, SunOutlined } from '@ant-design/icons'
import { useThemeStore } from '@renderer/store/themeStore'

export const ThemeSwitcher: FC = () => {
  const { theme, toggleTheme } = useThemeStore()

  return (
    <Tooltip title={theme === 'modern-dark' ? '切换到浅色主题' : '切换到深色主题'}>
      <Button
        type="text"
        icon={theme === 'modern-dark' ? <SunOutlined /> : <MoonOutlined />}
        onClick={toggleTheme}
      />
    </Tooltip>
  )
}
```

## 主题变量列表

### 颜色变量

| 变量名 | 说明 |
|--------|------|
| `--bg-primary` | 主背景色 |
| `--bg-secondary` | 次背景色（卡片、面板） |
| `--bg-tertiary` | 第三背景色（悬停、选中） |
| `--accent-primary` | 主强调色（按钮、链接） |
| `--accent-secondary` | 次强调色（渐变、悬停） |
| `--text-primary` | 主文字色 |
| `--text-secondary` | 次文字色（描述、提示） |
| `--border-color` | 边框颜色 |
| `--shadow-color` | 阴影颜色 |

### Ant Design 覆盖变量

| 变量名 | 说明 |
|--------|------|
| `--ant-primary-color` | 主色调 |
| `--ant-primary-color-hover` | 悬停主色调 |
| `--ant-text-color` | 文字颜色 |
| `--ant-text-color-secondary` | 次要文字颜色 |
| `--ant-bg-color` | 组件背景色 |
| `--ant-border-color` | 组件边框色 |

## 添加新主题

### 步骤

1. **创建主题 CSS 文件**

```css
/* src/renderer/src/assets/themes/my-theme.css */
[data-theme="my-theme"] {
  --bg-primary: #...;
  --bg-secondary: #...;
  /* ... 其他变量 */
}
```

2. **导入主题文件**

```typescript
// src/renderer/src/main.tsx
import './assets/themes/my-theme.css'
```

3. **更新类型定义**

```typescript
// src/renderer/src/store/themeStore.ts
type Theme = 'modern-dark' | 'clean-light' | 'my-theme'
```

4. **添加切换选项**

```typescript
<Select value={theme} onChange={setTheme}>
  <Select.Option value="modern-dark">赛博紫夜</Select.Option>
  <Select.Option value="clean-light">简洁专业</Select.Option>
  <Select.Option value="my-theme">我的主题</Select.Option>
</Select>
```

## 注意事项

1. **变量一致性** - 所有主题必须定义相同的变量
2. **Ant Design 覆盖** - 深色主题需要覆盖 `.ant-typography` 等组件
3. **过渡动画** - 主题切换时添加过渡效果
4. **存储持久化** - 主题选择保存到 localStorage
