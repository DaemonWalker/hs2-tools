### 带状态的组件

```typescript
// wails/frontend/src/components/share/Counter.tsx
import { FC, useState } from 'react'
import { Button, Space } from 'antd'

interface CounterProps {
  initialValue?: number
  onChange?: (value: number) => void
}

export const Counter: FC<CounterProps> = ({
  initialValue = 0,
  onChange
}) => {
  const [count, setCount] = useState(initialValue)

  const increment = () => {
    const newValue = count + 1
    setCount(newValue)
    onChange?.(newValue)
  }

  const decrement = () => {
    const newValue = count - 1
    setCount(newValue)
    onChange?.(newValue)
  }

  return (
    <Space>
      <Button onClick={decrement}>-</Button>
      <span>{count}</span>
      <Button onClick={increment}>+</Button>
    </Space>
  )
}
```

## 性能优化

### 1. memo 优化

```typescript
import { FC, memo } from 'react'

interface ExpensiveComponentProps {
  data: Data
}

export const ExpensiveComponent: FC<ExpensiveComponentProps> = memo(
  ({ data }) => {
    // 昂贵的渲染逻辑
    return <div>{/* ... */}</div>
  },
  // 自定义比较函数（可选）
  (prevProps, nextProps) => {
    return prevProps.data.id === nextProps.data.id
  }

```

### 2. useCallback

```typescript
import { FC, useCallback } from 'react'

export const ParentComponent: FC = () => {
  const [count, setCount] = useState(0)

  // 使用 useCallback 避免子组件不必要的重渲染
  const handleClick = useCallback(() => {
    console.log('Clicked')
  }, []) // 空依赖数组，永远不变

  return (
    <div>
      <p>{count}</p>
      <ChildComponent onClick={handleClick} />
    </div>
  )
}
```

### 3. useMemo

```typescript
import { FC, useMemo } from 'react'

export const DataList: FC<{ items: Item[] }> = ({ items }) => {
  // 昂贵的计算使用 useMemo 缓存

    <ul>
      {sortedItems.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  )
}
```

## 错误处理

### Error Boundary

```typescript
import { Component, ErrorInfo, ReactNode } from 'react'

interface Props {
  children: ReactNode
  fallback?: ReactNode
}

interface State {
  hasError: boolean
  error?: Error
}

export class ErrorBoundary extends Component<Props, State> {
  state: State = { hasError: false }

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error }
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    console.error('Error caught by boundary:', error, errorInfo)
  }

  render() {
    if (this.state.hasError) {
      return this.props.fallback || (
        <div>出错了: {this.state.error?.message}</div>
      )
    }

    return this.props.children
  }
}

// 使用
<ErrorBoundary fallback={<ErrorPage />}>
  <MyComponent />
</ErrorBoundary>
```

## UI 组件库规范

### 优先使用 Ant Design

**原则：优先使用 Ant Design 提供的组件，而非自行实现。**

```typescript
// ✅ 推荐：使用 Ant Design 组件
import { Drawer, Button, Modal, Card, Tabs } from 'antd'

// 使用 Drawer 组件
<Drawer
  title="详细信息"
  placement="bottom"
  open={visible}
  onClose={handleClose}
  height="55%"
>
  <Content />
</Drawer>

// ❌ 避免：自行实现抽屉
<div className="custom-drawer">
  <div className="drawer-header">...</div>
  <div className="drawer-body">...</div>
</div>
```

**原因：**
- Ant Design 组件经过充分测试，稳定可靠
- 内置动画、响应式、无障碍支持
- 统一的设计语言和交互体验
- 减少维护成本

**例外情况（允许自定义实现）：**
- Ant Design 没有提供该组件
- 需要高度定制化，Ant Design 无法满足需求
- 自定义组件更简单且复用性低

### 自定义组件原则

如需自定义组件，应遵循：
- 保持与 Ant Design 一致的设计语言
- 支持相同的 API 模式（如 `open`/`onClose`）
- 添加适当的 TypeScript 类型定义

### 横向三栏布局

抽屉内容推荐使用横向三栏布局：

```
┌─────────────────────────────────────────────────────┐
│  [图片区域]        [模组列表]        [信息区域]       │
│  flex: 0 0 auto    flex: 0 0 480px   flex: 1 1 auto │
│  高度自适应        固定宽度           填充剩余      │
└─────────────────────────────────────────────────────┘
```

**CSS 实现：**

```css
/* 容器 */
.drawer-content {
  height: 100%;
  display: flex;
  gap: 12px;
}

/* 左栏：图片（宽度自适应，最大宽度限制） */
.drawer-section.drawer-image {
  flex: 0 0 auto;
  height: 100%;
  max-width: 25%;    /* 容器最大宽度为父容器的25% */
}

.drawer-section.drawer-image img {
  height: 100%;      /* 高度填满 */
  width: auto;       /* 宽度自适应 */
  max-width: 100%;   /* 图片不超过容器宽度 */
}

/* 中栏：固定宽度 */
.drawer-section.drawer-mods {
  flex: 0 0 480px;   /* 固定宽度 */
  height: 100%;
}

/* 右栏：填充剩余 */
.drawer-section.drawer-info {
  flex: 1 1 auto;    /* 占据剩余空间 */
  height: 100%;
}
```

## 注意事项

1. **单一职责** - 一个组件只做一件事
2. **Props 数量** - 超过 5 个 props 考虑拆分
3. **条件渲染** - 提前返回处理加载和错误状态
4. **Key 属性** - 列表渲染必须提供 key
5. **类型安全** - 所有 props 和状态都要有类型
6. **优先使用 Ant Design** - 避免重复造轮子

## 共享组件说明

### DownloadButton

基于 Ant Design Button 封装的 Mod 下载按钮，支持下载进度显示。

**Props:**

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| modName | string | 是 | Mod 的唯一标识名称 |

**功能特性:**

- **三种状态显示**:
  - 默认: 显示"下载"按钮 (`type="primary"`)
  - 下载中: 显示进度条 + 取消按钮
  - 已完成: 显示"已完成"状态 (绿色文字，禁用状态)

- **自动获取下载链接**: 通过 `sideloadStore.getDownloadUrl` 获取
- **进度监听**: 使用 `useDownloadProgress` hook 监听下载进度
- **错误处理**: 下载失败自动重置状态

**使用示例:**

```typescript
import { DownloadButton } from '@renderer/components/share/DownloadButton'

// 在 Mod 列表中使用
<DownloadButton modName="mod.guid.here" />
```

**依赖组件:**
- `Button` (Ant Design) - 基础按钮
- `Progress` (Ant Design) - 进度条
- `DownloadOutlined`, `CheckCircleOutlined` (Ant Design Icons)
