## 技术栈

- **前端框架**: React 18 + TypeScript
- **桌面框架**: Wails v2.12 (Go 1.25)
- **构建工具**: Vite + Wails CLI
- **UI 组件**: Ant Design 5
- **状态管理**: Zustand
- **后端**: Go 1.25（内嵌于应用，另提供独立命令行工具）
- **样式方案**: Tailwind CSS + CSS 变量 + 主题系统
