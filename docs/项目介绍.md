# 项目介绍

HS2-Tools 是一个基于 Wails (Go) + React + TypeScript 的桌面应用，专为 Honey Select 2 (HS2) 游戏玩家设计，提供一站式的角色卡、场景和模组管理解决方案。

## 项目背景

Honey Select 2 是一款流行的角色创建和场景编辑游戏，玩家社区创作了大量的角色卡、场景和 Mod 资源。然而，管理这些资源面临以下挑战：

1. **资源分散** - 角色卡、场景、Mod 分散在不同目录
2. **依赖复杂** - 角色卡和场景需要特定的 Mod 才能正常显示
3. **下载困难** - 需要从多个网站手动下载缺失的 Mod
4. **缺少预览** - 无法快速浏览大量资源

HS2-Tools 旨在解决这些问题，提供统一的资源管理和自动化的 Mod 补全功能。

## 技术选型说明

### 为什么选择 Wails？

- **轻量高效** - 使用系统原生 WebView，应用体积小、内存占用低
- **Go 原生** - 后端直接使用 Go 编写，与高性能工具代码共享同一语言
- **前后端一体** - 通过 Bind 机制直接调用 Go 方法，无需额外 IPC 进程
- **单文件部署** - 编译为单个可执行文件，前端产物内嵌其中

### 为什么选择 Go？

- **高性能** - 下载器和扫描器需要处理大量 I/O 操作
- **并发能力** - Goroutine 轻松实现并发下载和扫描
- **单文件部署** - 编译为单个可执行文件
- **跨平台编译** - 轻松构建 Windows/Linux/macOS 版本

### 为什么选择 Zustand？

- **轻量简单** - API 简洁，学习成本低
- **TypeScript 友好** - 完整的类型支持
- **无样板代码** - 相比 Redux 大幅减少代码量
- **异步友好** - 天然支持异步操作

## 用户群体

HS2-Tools 主要面向以下用户：

1. **HS2 玩家** - 管理自己的角色卡和场景收藏
2. **Mod 作者** - 整理和分享自己的 Mod 作品
3. **资源收集者** - 批量下载和管理大量资源
