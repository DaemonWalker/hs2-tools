# 项目介绍

HS2-Tools 是一个基于 **.NET 8 + WPF** 的桌面应用，专为 Honey Select 2 (HS2) 游戏玩家设计，提供一站式的角色卡、场景和模组管理解决方案。

## 项目背景

Honey Select 2 是一款流行的角色创建和场景编辑游戏，玩家社区创作了大量的角色卡、场景和 Mod 资源。然而，管理这些资源面临以下挑战：

1. **资源分散** — 角色卡、场景、Mod 分散在不同目录
2. **依赖复杂** — 角色卡和场景需要特定的 Mod 才能正常显示
3. **下载困难** — 需要从多个网站手动下载缺失的 Mod
4. **缺少预览** — 无法快速浏览大量资源

HS2-Tools 旨在解决这些问题，提供统一的资源管理和自动化的 Mod 补全功能。

## 功能特性

| 功能 | 描述 |
|------|------|
| 🎮 游戏路径设置 | 配置 HS2 游戏目录，自动校验 `HoneySelect2.exe` |
| 📊 数据分析 | 三阶段扫描本地 Mod、场景、角色卡，统计 Mod 使用情况 |
| 👤 角色卡浏览 | 虚拟化网格（缩略图、搜索、zh-CN 排序、收藏），详情面板显示 Mod 依赖 |
| 🖼️ 场景浏览 | 场景网格 + 按角色名智能整理（归档到 `hs_tools_<文件夹>`） |
| 📦 Mod 管理 | 本地 Mod 表格（使用次数、未使用筛选） |
| 🌐 Sideload 数据库 | 浏览 BetterRepack 全量 Mod 库（12k+ 条目），在线更新 |
| ⬇️ Mod 下载 | 断点续传、代理（http/https/socks5）、取消/重试、实时进度 |
| 🧩 缺失补全 | 一键批量下载被引用但本地缺失的 Mod |
| 🔍 卡片探索器 | 单卡查看（人物/场景两种布局） |
| 🚀 快速启动 | 一键启动游戏 / 工作室，支持防休眠 |

## 架构概览

```
┌─────────────────────────────────────────────────────┐
│                 WPF 视图层（Views）                  │
│   8 个独立 Window（WindowManager 单例 + Hide/Show）  │
└──────────────────────┬──────────────────────────────┘
                       │ DataBinding（MVVM）
┌──────────────────────┴──────────────────────────────┐
│              ViewModel 层（CommunityToolkit.Mvvm）   │
│        每页一个 VM，订阅服务事件，不直接引用窗口      │
└──────────────────────┬──────────────────────────────┘
                       │ 直接调用（同进程，无 IPC）
┌──────────────────────┴──────────────────────────────┐
│                服务层（Services，单例）              │
│  Config / Scanner / Downloader+DownloadManager /    │
│  Sideloader / SideloadDatabase / GameLauncher /     │
│  ErrorLog                                           │
└─────────────────────────────────────────────────────┘
```

```
hs2-tools/

└── docs/                       # 项目文档
```

## 技术选型说明

### 为什么是 .NET 8 + WPF？

- **Windows 专用桌面** — 目标用户全部在 Windows 上玩 HS2，WPF 提供原生体验与最低运行时开销
- **强类型 + MVVM 成熟生态** — CommunityToolkit.Mvvm 源生成器，无反射开销
- **单文件自包含部署** — `dotnet publish` 产出单个 exe，用户无需安装 .NET
- **LTS 长期支持** — .NET 8 为长期支持版本

### 关键依赖

| 依赖 | 用途 |
|------|------|
| CommunityToolkit.Mvvm | MVVM 基础（ObservableObject / RelayCommand） |
| HtmlAgilityPack | 爬虫目录页 HTML 解析 |
| xUnit | 单元测试（含合成 PNG/zipmod 夹具、本地 HTTP 测试服务器） |

## 用户群体

1. **HS2 玩家** — 管理自己的角色卡和场景收藏
2. **Mod 作者** — 整理和分享自己的 Mod 作品
3. **资源收集者** — 批量下载和管理大量资源
