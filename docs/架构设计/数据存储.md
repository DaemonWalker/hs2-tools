# 数据存储

本文档介绍 HS2-Tools 的数据存储方案。

## 存储概览

HS2-Tools 使用多种存储方式满足不同需求：

| 存储类型 | 用途 | 位置 | 格式 |
|----------|------|------|------|
| JSON 文件 | 应用设置 | `用户配置目录/hs2-tools/setting.json` | JSON |
| JSON 文件 | 本地 Mod 数据 | `用户配置目录/hs2-tools/localMods.json` | JSON |
| 内嵌资源 | Sideload 基础数据 | 可执行文件内嵌 `resources/sideload.zip` | ZIP 内 JSON |
| LocalStorage | 临时 UI 状态 | WebView 存储 | 键值对 |
| Zustand Store | 运行时状态 | 内存 | 对象 |

**配置目录**：通过 Go 的 `os.UserConfigDir()` 获取，Windows 下即 `%APPDATA%/hs2-tools/`。

## 数据分类

### 用户配置

| 数据 | 类型 | 存储 | 说明 |
|------|------|------|------|
| 游戏路径 | 设置 | setting.json | HS2 安装目录 |
| 代理设置 | 设置 | setting.json | HTTP 代理配置 |
| Windows 休眠设置 | 设置 | setting.json | 是否禁用休眠 |
| 主题偏好 | 设置 | LocalStorage | 深色/浅色主题 |

### 业务数据

| 数据 | 类型 | 存储 | 说明 |
|------|------|------|------|
| 本地 Mod 列表 | Mod 数据 | localMods.json | 已安装的 Mod |
| Sideload Mod 映射 | Mod 数据 | 内嵌 sideload.zip / 爬虫结果 | GUID → URL 映射 |
| 扫描结果缓存 | 缓存 | 内存 | 临时缓存 |
| 下载任务状态 | 任务 | Store | 运行时状态 |

## JSON 文件存储

### 存储实现

配置持久化由 `wails/internal/utils/config.go` 提供：

```go
// wails/internal/utils/config.go

// getConfigDir 获取配置文件目录：os.UserConfigDir()/hs2-tools/
func getConfigDir() (string, error) {
    configDir, err := os.UserConfigDir()
    if err != nil {
        return "", err
    }
    dir := filepath.Join(configDir, "hs2-tools")
    if err := os.MkdirAll(dir, 0755); err != nil {
        return "", err
    }
    return dir, nil
}

// SaveJSON 将数据保存为 JSON 文件（缩进格式）
func SaveJSON(filename string, data interface{}) error

// LoadJSON 从 JSON 文件加载数据；文件不存在时返回 nil
func LoadJSON(filename string) (map[string]interface{}, error)

// 设置读写
func SaveSettings(settings interface{}) error         // setting.json
func LoadSettings() (map[string]interface{}, error)

// 本地 Mod 数据读写
func SaveLocalMods(mods interface{}) error            // localMods.json
func LoadLocalMods() (map[string]interface{}, error)
```

### 前端调用

设置与 Mod 数据通过 App 绑定方法读写：

```typescript
import ipcUtils from '../logic/ipcUtils'

// 保存设置
await ipcUtils.saveSettings({ path: 'C:\\HS2', proxy: { uri: 'http://127.0.0.1:7890' } })

// 加载设置
const settings = await ipcUtils.loadSettings()

// 保存/加载本地 Mod 数据
await ipcUtils.saveLocalMods(mods)
const mods = await ipcUtils.loadLocalMods()
```

### 数据结构

**setting.json**：

```json
{
  "path": "C:\\HS2",
  "proxy": {
    "uri": "http://127.0.0.1:7890",
    "username": "",
    "password": ""
  },
  "windowsSleep": {
    "disabled": true
  }
}
```

**localMods.json**（GUID → Mod 信息）：

```json
{
  "author.modname.version": {
    "name": "Mod 名称",
    "version": "1.0.0",
    "path": "C:\\HS2\\mods\\mod.zipmod"
  }
}
```

## Sideload 数据

### 基础数据（内嵌）

BetterRepack 的基础数据包通过 `//go:embed resources/sideload.zip` 内嵌在可执行文件中，`InitSideload` 方法解压其中的 `sideload.json` 并返回：

```go
// wails/app.go
func (a *App) InitSideload() (map[string]interface{}, error) {
    data, err := sideloadZip.ReadFile("resources/sideload.zip")
    // 写入临时文件 → 解压 → 读取 sideload.json
    result, err := utils.ExtractZipJSON(tmpFile, "sideload.json")
    return result, nil
}
```

### 数据更新（爬虫）

运行 Sideloader 爬虫可获取最新的 Mod 映射，结果通过 `sideloader:complete` 事件返回给前端 Store：

```
前端调用 ipcUtils.runSideloader()
    ↓
Go 爬虫抓取 Mod 映射（10 并发，可取消）
    ↓
sideloader:progress 事件推送进度
    ↓
sideloader:complete 事件返回完整数据
    ↓
前端更新 sideloadStore
```

### 数据格式

```json
{
  "author.modname.version": "download/AISHS2/mod.zipmod",
  "another.mod.v1": "download/AISHS2/another.zipmod"
}
```

## LocalStorage 存储

### 主题存储

```typescript
// wails/frontend/src/store/themeStore.ts
const THEME_KEY = 'hs2-tools-theme'

export const useThemeStore = create<ThemeState>((set) => ({
  theme: localStorage.getItem(THEME_KEY) || 'modern-dark',

  setTheme: (theme) => {
    localStorage.setItem(THEME_KEY, theme)
    document.documentElement.setAttribute('data-theme', theme)
    set({ theme })
  }
}))
```

## Zustand Store

### Store 设计原则

1. **单一职责** - 每个 Store 管理一类状态
2. **持久化分离** - Store 负责运行时状态，持久化通过绑定方法写 JSON 文件
3. **不可变更新** - 使用展开运算符创建新对象

### 设置 Store

```typescript
// wails/frontend/src/store/settingStore.ts
import { create } from 'zustand'
import ipcUtils from '../logic/ipcUtils'

export const useSettingStore = create<SettingState>((set, get) => ({
  settings: { path: undefined },

  init: async () => {
    const settings = await ipcUtils.loadSettings()
    set({ settings: settings || { path: undefined } })
  },

  setPath: async (path) => {
    const settings = { ...get().settings, path }
    await ipcUtils.saveSettings(settings)
    set({ settings })
  }
}))
```

### 下载 Store

下载任务进度通过 `download:progress` / `download:complete` 事件驱动更新：

```typescript
// 监听下载事件并更新 Store
useEffect(() => {
  const unsubProgress = ipcUtils.onDownloadProgress((data) => {
    useDownloadStore.getState().updateProgress(data.guid, data)
  })
  const unsubComplete = ipcUtils.onDownloadComplete((data) => {
    useDownloadStore.getState().completeTask(data.guid, data.success)
  })
  return () => {
    unsubProgress()
    unsubComplete()
  }
}, [])
```

## 数据流

### 设置数据流

```
用户修改设置
    ↓
Store.setPath() 等 action
    ↓
ipcUtils.saveSettings()（Wails 绑定调用）
    ↓
Go: utils.SaveSettings() 写入 setting.json
    ↓
Store 状态更新
    ↓
UI 重新渲染
```

### Mod 数据流

```
扫描本地 Mods
    ↓
Go Scanner 批量解析 zipmod
    ↓
返回 ModModel
    ↓
ipcUtils.saveLocalMods() 写入 localMods.json
    ↓
Store 更新
```

### Sideload 数据流

```
应用启动
    ↓
ipcUtils.initSideload() 加载内嵌基础数据
    ↓
用户手动刷新 → 运行 Sideloader
    ↓
sideloader:complete 事件返回最新数据
    ↓
前端 Store 更新
```

## 数据备份与迁移

配置数据为纯 JSON 文件，可直接复制备份：

- **备份**：复制 `%APPDATA%/hs2-tools/` 目录下的 `setting.json` 和 `localMods.json`
- **迁移**：将文件放入新机器相同位置即可
- **重置**：删除对应 JSON 文件，应用下次启动时使用默认值

## 性能优化

### 1. 批量写入

Mod 数据整体作为一个 JSON 对象一次写入，避免逐条 I/O：

```go
// 一次性序列化写入
bytes, err := json.MarshalIndent(data, "", "  ")
return os.WriteFile(path, bytes, 0644)
```

### 2. 缓存策略

```typescript
// 前端内存缓存
const cache = new Map<string, any>()

export const getCachedMod = (guid: string) => {
  if (cache.has(guid)) {
    return cache.get(guid)
  }
  const mod = loadMod(guid)
  cache.set(guid, mod)
  return mod
}
```

## 数据安全

### 1. 输入验证

```typescript
const validateSetting = (setting: unknown): setting is SettingModel => {
  if (typeof setting !== 'object' || setting === null) return false
  const s = setting as any
  return typeof s.path === 'string' || s.path === undefined
}
```

### 2. 文件写入安全

- 配置文件目录由 `os.MkdirAll` 确保存在
- JSON 序列化失败时返回错误，不写入损坏数据
- 文件不存在时 `LoadJSON` 返回 `nil`，调用方使用默认值
