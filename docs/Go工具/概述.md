# Go 工具概述

本文档介绍 HS2-Tools 的 Go 工具集。

## 工具集简介

迁移到 Wails 后，Go 代码直接编译进应用（`wails/internal/`），同时提供可独立编译的命令行工具（`wails/cmd/`）：

| 工具 | 功能 | 主要特性 |
|------|------|----------|
| `downloader` | 文件下载 | 断点续传、代理支持、进度回调、context 取消 |
| `scanner` | 文件扫描 | 目录遍历、PNG 解析、zipmod 解析、批量并发 |
| `sideloader` | 数据爬取 | HTTP 爬取（goquery，10 并发、可取消）、ZIP 流式解析 |

## 设计目标

1. **高性能** - Go 的并发能力和运行效率
2. **内嵌应用** - 应用内直接调用，无外部进程依赖
3. **独立可用** - 同一套代码可编译为独立命令行工具
4. **跨平台** - 支持 Windows、macOS、Linux

## 架构关系

```
前端 (React)
    ↓ Wails 绑定
App 绑定方法 (wails/app.go)
    ↓ 直接函数调用（同进程）
Go 内部包 (wails/internal/)
    ↓
文件系统 / 网络

命令行工具 (wails/cmd/)
    ↓ 复用同一套 internal 包
wails/internal/
```

## 应用内集成

### 绑定方法封装

`wails/app.go` 将 internal 包封装为 `App` 导出方法，前端通过 Wails 绑定直接调用：

```go
// wails/app.go
import "wails/internal/scanner"

func (a *App) GetAllFiles(path string, options *scanner.Options) ([]string, error) {
    return scanner.ScanDirectory(path, options)
}

func (a *App) ReadPngForMod(path string) ([]string, error) {
    return scanner.ReadPngMods(path)
}
```

```typescript
// 前端调用
const files = await ipcUtils.getAllFiles(path, { targetExtension: ['.png'] })
```

### 异步任务与事件

下载、爬虫等长耗时任务在 Goroutine 中执行，通过事件推送进度：

```go
// wails/app.go
go func() {
    err := dl.Download(url, output, true, func(p downloader.ProgressMessage) {
        wailsRuntime.EventsEmit(a.ctx, "download:progress", ...)
    })
    wailsRuntime.EventsEmit(a.ctx, "download:complete", ...)
}()
```

## 命令行工具

### 通用接口规范

命令行工具支持命令行参数或 JSON 标准输入两种模式，统一输出 JSON：

```json
{
  "success": true,
  "data": { },
  "error": null
}
```

**命令行模式**：

```bash
scanner -action readPngMods -path "C:\card.png"
```

**JSON 模式**（推荐批量操作）：

```bash
echo '{"action":"readPngMods","path":"C:\\card.png"}' | scanner -json
```

详细接口说明见 [../API参考/Go工具接口](../API参考/Go工具接口.md)。

## 构建和分发

### 应用构建（推荐）

```bash
# 应用内已包含全部 Go 功能，无需单独编译工具
npm run wails:build
```

### 独立工具编译

```bash
cd wails

go build -ldflags="-s -w" -o build/bin/scanner.exe ./cmd/scanner
go build -ldflags="-s -w" -o build/bin/downloader.exe ./cmd/downloader
go build -ldflags="-s -w" -o build/bin/sideloader.exe ./cmd/sideloader
```

### 跨平台编译

```bash
# Windows
go build -ldflags="-s -w" -o scanner.exe ./cmd/scanner

# Linux
GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o scanner ./cmd/scanner

# macOS
GOOS=darwin GOARCH=amd64 go build -ldflags="-s -w" -o scanner-mac ./cmd/scanner
```

## 调试技巧

### 独立运行

```bash
cd wails

# 直接运行测试（无需编译）
go run ./cmd/scanner -action scanDir -path "C:\\HS2"

# JSON 模式测试
echo '{"action":"fileExists","path":"test.png"}' | go run ./cmd/scanner -json
```

### 查看输出

```bash
# 爬虫日志输出到 stdout
go run ./cmd/sideloader -proxy "http://127.0.0.1:7890"
```

## 注意事项

1. **路径处理** - Windows 路径需要正确处理反斜杠
2. **编码问题** - 中文路径需要 UTF-8 编码
3. **内存使用** - 大文件处理使用流式读取
4. **并发安全** - 多协程访问共享数据需要加锁（如 `sideloaderMu`）
