# Go 扫描器

本文档介绍 Go 扫描器的实现和使用。

## 功能特性

- **目录扫描** - 递归遍历目录，支持过滤
- **PNG 解析** - 提取角色名称、Mod GUID、缩略图
- **zipmod 解析** - 提取 manifest.xml 信息
- **批量处理** - 并发处理多个文件
- **跨盘符移动** - 支持不同盘符间的文件移动
- **错误容错** - 图片读取失败返回空字符串而非错误

## 使用方法

### 命令行模式

```bash
scanner [选项]

选项:
  -action string   操作类型 (必需)
  -path string     输入路径 (必需)
  -target string   目标路径 (moveFile 用)
  -exclude string  排除目录，逗号分隔
  -ext string      目标扩展名，逗号分隔
  -json            从 stdin 读取 JSON 参数
```

### 支持的 Action

| Action | 说明 | 参数 |
|--------|------|------|
| `scanDir` | 扫描目录 | `path`, `options` |
| `readPngMods` | 提取 PNG 的 Mod GUID | `path` |
| `readPngNames` | 提取 PNG 的角色名称 | `path` |
| `readPngImage` | 提取 PNG 的缩略图 | `path` |
| `readZipMod` | 解析单个 zipmod | `path` |
| `readZipModBatch` | 批量解析 zipmod | `paths`, `concurrency` |
| `readPngModsBatch` | 批量提取 PNG Mods | `paths`, `concurrency` |
| `readPngNamesBatch` | 批量提取 PNG 名称 | `paths`, `concurrency` |
| `readPngImagesBatch` | 批量提取 PNG 图像 | `paths`, `concurrency` |
| `readPngPageDataBatch` | 批量提取页面数据（名称+缩略图） | `paths`, `concurrency` |
| `moveFile` | 移动文件 | `path`, `targetPath` |
| `checkDir` | 检查并创建目录 | `path` |
| `fileExists` | 检查文件是否存在 | `path` |

### 示例

```bash
# 扫描目录
./scanner -action scanDir -path "C:\HS2\UserData\chara\female" -ext ".png"

# 提取 PNG Mods
./scanner -action readPngMods -path "C:\card.png"

# 移动文件
./scanner -action moveFile -path "C:\source.png" -target "D:\dest.png"

# JSON 批量模式
$json = '{"action":"readZipModBatch","paths":["a.zipmod","b.zipmod"],"concurrency":4}'
echo $json | ./scanner -json
```

// Request 请求结构
type Request struct {
  Action      string   `json:"action"`
  Path        string   `json:"path"`
  Paths       []string `json:"paths,omitempty"`
  TargetPath  string   `json:"targetPath"`
  Options     *Options `json:"options,omitempty"`
  Concurrency int      `json:"concurrency,omitempty"`
}

// Options 扫描选项
type Options struct {
  ExcludeDir      []string `json:"excludeDir,omitempty"`
  TargetExtension []string `json:"targetExtension,omitempty"`
}

// Response 响应结构
type Response struct {
  Success bool        `json:"success"`
  Data    interface{} `json:"data,omitempty"`
  Error   string      `json:"error,omitempty"`
}

// ModInfo Mod 信息
type ModInfo struct {
  Name    string `json:"name"`
  Version string `json:"version"`
  Path    string `json:"path"`
}

// ModModel Mod 模型 (guid -> ModInfo)
type ModModel map[string]ModInfo

### 目录扫描

```go
func scanDirectory(dir string, opts *Options) ([]string, error) {
  if opts == nil {
    opts = &Options{}
  }

  var files []string
  
  err := filepath.Walk(dir, func(path string, info os.FileInfo, err error) error {
    if err != nil {
      return nil // 跳过无法访问的文件
    }

    // 检查排除目录
    if info.IsDir() {
      for _, exclude := range opts.ExcludeDir {
        if strings.Contains(info.Name(), exclude) {
          return filepath.SkipDir
        }
      }
      return nil
    }

    // 检查扩展名
    if len(opts.TargetExtension) > 0 {
      ext := filepath.Ext(path)
      found := false
      for _, targetExt := range opts.TargetExtension {
        if strings.EqualFold(ext, targetExt) {
          found = true
          break
        }
      }
      if !found {
        return nil
      }
    }

    files = append(files, path)
    return nil
  })

  return files, err
}
```

### PNG 解析

#### 数据提取原理

Scanner 从 PNG 文件中提取数据的原理是**查找标记字符串之间的内容**：

```
原始数据: fullname<包裹字节>内容<包裹字节>personality
            ↑      ↑          ↑      ↑
         开始标记  首字节    尾字节  结束标记
```

| 数据类型 | 开始标记 | 结束标记 |
|---------|---------|---------|
| 角色名称 | `fullname` | `personality` |
| Mod GUID | `ModID` | `Slot` |

#### 字符串处理流程

提取到的原始字节需要经过以下处理步骤：

```
原始字节: B1 E7 82 BD E5 A4 A9 E4 BD BF AB
           │ └────────────┬────────────┘ │
        首字节       UTF-8内容       尾字节
           └─────────────────────────────┘
                    去掉首尾字节
                        ↓
              E7 82 BD E5 A4 A9 E4 BD BF
                        ↓
                    UTF-8解码
                        ↓
                    TrimSpace
                        ↓
              "炽天使"
```

**处理步骤说明：**

| 步骤 | 函数/操作 | 说明 | 示例 |
|------|----------|------|------|
| 1 | `searchBuffer` | 查找标记之间的字节 | `fullname...personality` |
| 2 | 切片操作 | 去掉首尾包裹字节 | `B1...AB` → `E7 82 BD...` |
| 3 | `string()` | UTF-8 解码 | `[]byte{0xE7...}` → `"炽"` |
| 4 | `TrimSpace()` | 去首尾空白 | `"  Alice  "` → `"Alice"` |

**注意：** 之前的版本包含替换字符(`�`)清理和特殊首字符(`%`, `:`, `!`, `"`, `$`)清理，现已移除，因为数据预处理已经去除了这些非法字符。

#### 实际案例

**案例 1: 中文名称**
```
原始字节: 66 75 6C 6C 6E 61 6D 65 B1 E7 82 BD E5 A4 A9 E4 BD BF AB 70 65 72 73 6F 6E 61 6C 69 74 79
          │____fullname____│ │ │__炽天使__│ │ │____personality___│
                           B1              AB

处理过程:
  1. 提取: B1 E7 82 BD E5 A4 A9 E4 BD BF AB
  2. 去首尾: E7 82 BD E5 A4 A9 E4 BD BF
  3. UTF-8解码: "炽天使"
  4. TrimSpace: "炽天使"

结果: ["炽天使"]
```

#### 核心代码

```go
var (
    nameStart = []byte("fullname")    // 角色名开始标记
    nameEnd   = []byte("personality") // 角色名结束标记
    modStart  = []byte("ModID")       // Mod开始标记
    modEnd    = []byte("Slot")        // Mod结束标记
)

// 从 PNG 提取角色名称
func readPngNames(filePath string) ([]string, error) {
    exists, _ := fileExists(filePath)
    if !exists {
        return []string{}, nil
    }

    data, err := os.ReadFile(filePath)
    if err != nil {
        return nil, err
    }

    return searchBuffer(nameStart, nameEnd, data), nil
}

// 从 PNG 提取 Mod GUID
func readPngMods(filePath string) ([]string, error) {
    exists, _ := fileExists(filePath)
    if !exists {
        return []string{}, nil
    }

    data, err := os.ReadFile(filePath)
    if err != nil {
        return nil, err
    }

    return searchBuffer(modStart, modEnd, data), nil
}

// 查找标记之间的所有内容
func searchBuffer(start, end, data []byte) []string {
    result := make(map[string]bool) // 去重
    
    for {
        // 查找开始标记
        startIndex := bytes.Index(data, start)
        if startIndex == -1 {
            break
        }
        
        // 从开始标记之后查找结束标记
        endIndex := bytes.Index(data[startIndex+len(start):], end)
        if endIndex == -1 {
            break
        }
        endIndex += startIndex + len(start)
        
        // 提取标记之间的内容
        content := data[startIndex+len(start) : endIndex]
        
        // 去掉首尾包裹字节（如 0xB1 和 0xAB）
        if len(content) > 2 {
            content = content[1 : len(content)-1]
        }
        
        // 转换为字符串并清洗
        if str := bufferToString(content); str != "" {
            result[str] = true
        }
        
        // 移动到结束标记之后继续搜索
        data = data[endIndex+len(end):]
    }
    
    // map 转 slice
    list := make([]string, 0, len(result))
    for str := range result {
        list = append(list, str)
    }
    return list
}

// 将 Buffer 转为字符串（简化版）
func bufferToString(buffer []byte) string {
    return strings.TrimSpace(string(buffer))
}
```

### 提取 PNG 缩略图

**实现原理：**

1. 读取整个 PNG 文件
2. 从文件末尾查找 `IEND` 标记
3. 截取从文件开头到 `IEND` 标记结束的所有数据
4. 将截取的数据编码为 Base64

**错误处理：**

- 文件不存在 → 返回空字符串
- 读取失败 → 返回空字符串  
- IEND 标记未找到 → 返回空字符串
- 成功 → 返回 Base64 编码的图像数据

```go
// readPngImage 读取单个 PNG 文件的缩略图（Base64）
// 读取失败时返回空字符串而不是错误
func readPngImage(filePath string) (string, error) {
    exists, _ := fileExists(filePath)
    if !exists {
        return "", nil
    }

    data, err := os.ReadFile(filePath)
    if err != nil {
        return "", nil
    }

    // 查找 IEND 标记位置
    pngEnd := []byte("IEND")
    endIndex := -1
    for i := len(data) - 1; i >= 3; i-- {
        if data[i] == pngEnd[3] && data[i-1] == pngEnd[2] &&
            data[i-2] == pngEnd[1] && data[i-3] == pngEnd[0] {
            endIndex = i + 1
            break
        }
    }

    if endIndex == -1 || endIndex > len(data) {
        return "", nil
    }

    // 截取纯 PNG 图像数据
    pngData := data[:endIndex]
    return base64.StdEncoding.EncodeToString(pngData), nil
}
```

### 批量获取页面数据

同时获取名称和缩略图，名称读取失败则跳过，缩略图读取失败返回空字符串：

```go
// readPngPageDataBatch 批量获取页面数据（名称 + 缩略图）
func readPngPageDataBatch(filePaths []string, concurrency int) ([]PngPageDataResult, error) {
    if concurrency <= 0 {
        concurrency = 4
    }

    results := make([]PngPageDataResult, 0, len(filePaths))
    var mutex sync.Mutex

    // 创建任务通道
    taskChan := make(chan string, len(filePaths))
    for _, path := range filePaths {
        taskChan <- path
    }
    close(taskChan)

    // 创建工作池
    var wg sync.WaitGroup
    for i := 0; i < concurrency; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for path := range taskChan {
                // 同时读取名称和缩略图
                names, nameErr := readPngNames(path)
                imageData, imageErr := readPngImage(path)

                // 名称读取失败则跳过
                if nameErr != nil {
                    continue
                }

                // 确保 names 不是 nil
                if names == nil {
                    names = []string{}
                }

                // 图片读取失败时，返回空字符串
                if imageErr != nil {
                    imageData = ""
                }

                mutex.Lock()
                results = append(results, PngPageDataResult{
                    Path:      path,
                    Names:     names,
                    ImageData: imageData,
                })
                mutex.Unlock()
            }
        }()
    }

    wg.Wait()
    return results, nil
}
```

### zipmod 解析

```go
func readZipMod(path string) (ModModel, error) {
  r, err := zip.OpenReader(path)
  if err != nil {
    return nil, err
  }
  defer r.Close()

  // 查找 manifest.xml
  for _, f := range r.File {
    if strings.EqualFold(f.Name, "manifest.xml") {
      rc, err := f.Open()
      if err != nil {
        return nil, err
      }
      defer rc.Close()

      data, err := io.ReadAll(rc)
      if err != nil {
        return nil, err
      }

      return parseManifest(data, path)
    }
  }

  return nil, fmt.Errorf("manifest.xml not found")
}

func parseManifest(data []byte, path string) (ModModel, error) {
  var manifest struct {
    GUID    string `xml:"guid"`
    Name    string `xml:"name"`
    Version string `xml:"version"`
  }

  if err := xml.Unmarshal(data, &manifest); err != nil {
    return nil, err
  }

  return ModModel{
    manifest.GUID: {
      Name:    manifest.Name,
      Version: manifest.Version,
      Path:    path,
    },
  }, nil
}
```

### 批量处理

```go
func readPngModsBatch(paths []string, concurrency int) ([]PngModResult, error) {
  if concurrency <= 0 {
    concurrency = 4
  }

  sem := make(chan struct{}, concurrency)
  var wg sync.WaitGroup
  results := make([]PngModResult, len(paths))
  var mu sync.Mutex

  for i, path := range paths {
    wg.Add(1)
    sem <- struct{}{}

    go func(index int, p string) {
      defer wg.Done()
      defer func() { <-sem }()

      modIds, err := readPngMods(p)

      mu.Lock()
      results[index] = PngModResult{
        Path:   p,
        ModIds: modIds,
        Error:  errToString(err),
      }
      mu.Unlock()
    }(i, path)
  }

  wg.Wait()
  return results, nil
}
```

### 文件移动

```go
func moveFile(src, dst string) error {
  // 确保目标目录存在
  dir := filepath.Dir(dst)
  if err := os.MkdirAll(dir, 0755); err != nil {
    return fmt.Errorf("failed to create target directory: %w", err)
  }

  // 尝试直接重命名（同盘符）
  err := os.Rename(src, dst)
  if err == nil {
    return nil
  }

  // 跨盘符：复制后删除
  if err := copyFile(src, dst); err != nil {
    return fmt.Errorf("failed to copy file: %w", err)
  }

  if err := os.Remove(src); err != nil {
    return fmt.Errorf("failed to remove source file: %w", err)
  }

  return nil
}

func copyFile(src, dst string) error {
  input, err := os.ReadFile(src)
  if err != nil {
    return err
  }
  return os.WriteFile(dst, input, 0644)
}
```

// 通用执行函数
const runScanner = (request: ScannerRequest): Promise<ScannerResponse> => {
  return new Promise((resolve, reject) => {
    const process = spawn(scannerPath, ['-json'])

    process.stdin.write(JSON.stringify(request) + '\n')
    process.stdin.end()

    let output = ''
    process.stdout.on('data', (data) => {
      output += data.toString()
    })

    process.on('close', (code) => {
      try {
        const response = JSON.parse(output)
        if (response.success) {
          resolve(response)
        } else {
          reject(new Error(response.error))
        }
      } catch (e) {
        reject(new Error('Invalid JSON response'))
      }
    })
  })
}

## 性能优化

1. **并发控制** - 信号量限制并发数，避免系统过载
2. **流式读取** - PNG 解析使用流式读取，减少内存占用
3. **批量处理** - 一次处理多个文件，减少 IPC 开销
4. **快速失败** - 单个文件失败不影响整体结果
5. **错误容错** - 图片读取失败返回空字符串，不中断流程

## 注意事项

1. **编码问题** - 中文路径需要正确处理
2. **权限问题** - 访问受限目录可能失败
3. **内存限制** - 批量处理大量文件时注意内存
4. **文件锁** - 被占用的文件可能无法读取
5. **错误处理** - `readPngImage` 失败时返回空字符串而不是错误，确保流程不中断
