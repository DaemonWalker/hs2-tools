# 快速开始

## 环境要求

- Windows 10/11（x64）
- 开发：.NET 8 SDK
- 运行发布产物：无需安装 .NET（自包含单文件）

## 构建与运行

```bash
cd hs2-tools-csharp
dotnet build                          # 构建
dotnet run --project src/HS2Tools     # 开发模式启动应用
```

## 测试

```bash
dotnet test
```

当前 206 项测试。默认全部通过的为单元/集成测试；以下基准与对照测试**默认跳过**，设置环境变量后运行：

| 环境变量 | 作用 |
|---|---|
| `HS2_REAL_CARD_DIRS` | 真实卡片目录（分号分隔），与旧版输出逐卡对照 |
| `HS2_REAL_MODS_DIR` | 真实 mods 目录，zipmod 全量扫描基准 |
| `HS2_REAL_GAME_DIR` | 真实游戏目录，三阶段扫描基准 |
| `HS2TOOLS_REAL_CRAWL=1` | 真实站点爬虫对照（约 30 分钟） |

示例：

```bash
HS2_REAL_GAME_DIR='F:\game\HS2V24' dotnet test --filter "FullyQualifiedName~Scan_RealGameDir"
```

## 打包发布

```bash
cd hs2-tools-csharp
dotnet publish src/HS2Tools/HS2Tools.csproj -c Release -r win-x64 \
  --self-contained -p:PublishSingleFile=true -o publish
```

产物：`publish/HS2Tools.exe`（单文件自包含，约 160MB）。内嵌 sideload.zip 数据库随单文件分发，首次运行无网络也可用。

## 首次使用

1. 启动 `HS2Tools.exe`
2. 首页「游戏路径」选择 HS2 游戏目录（校验 `HoneySelect2.exe`，绿点为有效）
3. 点「数据分析」执行三阶段扫描（Mod → 场景 → 角色卡）
4. 之后即可浏览角色卡/场景、查看缺失 Mod、一键补全

## 数据位置

全部存储在 `%AppData%/hs2-tools/`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 统一配置（游戏路径、代理、防休眠、收藏、本地 Mod 库、使用统计） |
| `sideload.json` | 爬虫更新后的 sideload 数据库（存在时优先于内嵌库） |
| `error.log` | 错误日志（追加写入，排障先看这里） |
