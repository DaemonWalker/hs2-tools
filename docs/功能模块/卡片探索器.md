# 卡片探索器

本文档介绍卡片探索器功能，用于查看本地 PNG 卡片文件的详细信息和模组依赖。

## 功能概述

卡片探索器允许用户：

- 查看本地 PNG 卡片文件（人物卡/场景卡）
- 预览卡片图片
- 查看卡片所需的模组依赖列表
- 检查已拥有的模组和需要下载的模组
- 场景卡支持查看场景人物列表

## 页面路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/explorer` | 卡片探索器 | 查看本地 PNG 卡片文件 |

## 核心功能实现

### 1. 类型切换

使用 `Segmented` 组件切换人物卡/场景卡，切换时自动清空当前显示：

```typescript
const [type, setType] = useState<'chara' | 'scene'>('chara')

<Segmented
  value={type}
  onChange={(value) => {
    setType(value as 'chara' | 'scene')
    setFilePath('')  // 清空文件路径
    setShow(false)   // 清空显示
  }}
  options={[
    { label: '人物卡', value: 'chara', icon: <UserOutlined /> },
    { label: '场景卡', value: 'scene', icon: <BookOutlined /> }
  ]}
/>
```

### 2. 文件选择

支持两种方式选择文件：

- **点击浏览**：根据类型自动打开对应默认文件夹
  - 人物卡：`{gamePath}/UserData/chara/female`
  - 场景卡：`{gamePath}/UserData/Studio/scene`
- **拖拽上传**：拖拽 PNG 文件到输入框区域

```typescript
const selectFile = async () => {
  const subPath = type === 'chara' ? CHARA_FEMALE_PATH : SCENE_PATH
  const targetPath = gamePath ? `${gamePath}/${subPath}` : undefined
  
  // 检查目标文件夹是否存在
  const defaultPath = targetPath && await dirExists(targetPath) ? targetPath : undefined
  
  const selectedPath = await openFileSelector(defaultPath)
  if (selectedPath) setFilePath(selectedPath)
}
```

### 3. 智能布局组件

根据卡片类型自动切换布局：

```typescript
// wails/frontend/src/components/share/SmartCardLayout.tsx
export const SmartCardLayout: FC<SmartCardLayoutProps> = ({ filePath, type }) => {
  // 人物卡：左右布局（图片左，信息+模组右）
  if (type === 'chara') {
    return (
      <div style={verticalLayoutStyle}>
        <div style={verticalImageStyle}>{renderImage()}</div>
        <div style={verticalContentStyle}>
          <CharaInfo filePath={filePath} />
          <ModList filePath={filePath} />
        </div>
      </div>
    )
  }
  
  // 场景卡：三列布局（图片+人物左，模组右）
  if (type === 'scene') {
    return (
      <div style={sceneLayoutStyle}>
        <div style={sceneLeftColumnStyle}>
          <div style={sceneImageStyle}>{renderImage()}</div>
          <div style={sceneCharaListStyle}>
            <SceneInfo filePath={filePath} />
          </div>
        </div>
        <div style={sceneModColumnStyle}>
          <ModList filePath={filePath} />
        </div>
      </div>
    )
  }
}
```

### 4. 场景人物列表

场景卡专用组件，每行显示一个人物：

```typescript
// wails/frontend/src/components/scene/SceneInfo.tsx
export const SceneInfo: FC<IState> = ({ filePath }) => {
  const [charaNames, setCharaNames] = useState<string[]>([])
  
  useEffect(() => {
    readAllCharaNames(filePath).then((data) => {
      setCharaNames(data || [])
    })
  }, [filePath])
  
  return (
    <List
      header={
        <div style={{ padding: '8px 16px' }}>
          <Text strong>场景人物</Text>
          <Text type="secondary" style={{ marginLeft: 8 }}>
            ({charaNames.length} 个)
          </Text>
        </div>
      }
      size="small"
      dataSource={charaNames}
      renderItem={(name, index) => (
        <List.Item style={{ padding: '8px 16px' }}>
          <Text ellipsis style={{ flex: 1 }} title={name}>
            {index + 1}. {name}
          </Text>
        </List.Item>
      )}
      locale={{ emptyText: '未检测到场景人物' }}
    />
  )
}
```

### 5. 模组依赖列表

显示卡片所需的所有模组，标注已拥有和需下载状态：

```typescript
// wails/frontend/src/components/share/ModList.tsx
export const ModList: FC<IState> = ({ filePath }) => {
  const [mods, setMods] = useState<string[]>()
  const localMods = useModsSelector() // 从 store 获取本地模组列表
  
  const data = useMemo(() => 
    mods?.map((name) => ({ 
      name, 
      isLocal: !!localMods?.[name] 
    })) || [],
    [mods, localMods]
  )
  
  return (
    <Card 
      title={`模组依赖 (${data.length} 个)`}
      style={{ height: '100%' }}
    >
      <List
        dataSource={data}
        renderItem={(item) => (
          <List.Item>
            <span>{item.name}</span>
            {item.isLocal ? (
              <Tag color="success">已拥有</Tag>
            ) : (
              <DownloadButton modName={item.name} />
            )}
          </List.Item>
        )}
      />
    </Card>
  )
}
```

## 主要文件说明

| 文件 | 功能 |
|------|------|
| `CardExplorer.tsx` | 页面入口，处理类型切换、文件选择、拖拽上传 |
| `SmartCardLayout.tsx` | 根据类型自动切换布局（人物卡/场景卡） |
| `ModList.tsx` | 显示模组依赖列表，标注已拥有/需下载状态 |
| `SceneInfo.tsx` | 场景卡专用，显示场景人物列表 |
| `CharaInfo.tsx` | 人物卡专用，显示人物基本信息 |
| `PngViewer.tsx` | PNG 图片加载和预览 |

## 注意事项

1. **路径处理** - 文件选择器根据类型自动打开对应默认文件夹，需要游戏路径已正确设置
2. **文件类型** - 仅支持 `.png` 格式的卡片文件
3. **拖拽上传** - 拖拽区域支持从文件管理器直接拖拽文件
4. **布局自适应** - 人物卡左右布局，场景卡三列布局，各自优化显示效果
5. **清空逻辑** - 切换人物卡/场景卡类型时自动清空当前显示，避免数据混淆
