# 首页与初始化

本文档介绍 HS2-Tools 首页功能和使用流程。

## 功能概述

首页是应用的入口，提供以下功能模块：

| 模块 | 功能 | 对应组件 |
|------|------|----------|
| 数据分析 | 扫描本地角色卡、场景、Mod | `Scan` |
| 路径设置 | 配置 HS2 游戏目录 | `PathSetting` |
| 快速启动 | 一键启动游戏或工作室 | `GameLauncher` |
| 数据初始化 | 更新 Sideload 数据、补全 Mods | `SideloaderUpdate`, `SideloadInit` |
| 数据概览 | 显示本地资源统计 | `QuickStats` |

## 使用流程

### 首次使用

```
1. 路径设置
   └── 选择 HoneySelect2.exe 所在目录

2. 数据分析
   └── 点击「开始分析」按钮
       └── 按顺序扫描：Mods → 场景 → 角色卡

3. 更新 Sideload 数据
   └── 点击「更新数据」按钮
       └── 爬虫抓取 BetterRepack 数据

4. 补全缺失 Mods（可选）
   └── 点击「开始补全」
       └── 自动下载缺失的 Mod
```

### 日常使用

```
1. 启动应用
2. 查看数据概览
3. 快速启动游戏/工作室
4. 定期更新 Sideload 数据
```

## 功能模块详解

### 1. 路径设置 (PathSetting.tsx)

**功能**：配置 HS2 游戏目录并验证路径有效性

**实现**：

```typescript
// src/renderer/src/components/home/PathSetting.tsx
export const PathSetting: FC = () => {
  const { settings, setPath } = useSettingStore()
  const [pathValid, setPathValid] = useState<boolean | null>(null)
  const [checking, setChecking] = useState(false)

  // 使用自定义 hook 选择路径
  const { openSelectPath, loading } = usePathSelector({
    onSelect: async (selectedPath) => {
      await setPath(selectedPath)
      message.success('游戏路径已更新')
    }
  })

  // 验证路径有效性（检查是否存在 HoneySelect2.exe）
  useEffect(() => {
    if (!settings?.path) {
      setPathValid(null)
      return
    }

    const checkPath = async () => {
      setChecking(true)
      try {
        const gameExists = await fileExists(`${settings.path}/HoneySelect2.exe`)
        setPathValid(gameExists)
      } catch {
        setPathValid(false)
      } finally {
        setChecking(false)
      }
    }

    checkPath()
  }, [settings?.path])

  // 根据验证结果显示状态图标
  const getStatusIcon = () => {
    if (checking) return <Badge status="processing" />
    if (pathValid === null) return <Badge status="warning" />
    if (pathValid) return <CheckCircleOutlined style={{ color: 'var(--color-success)' }} />
    return <ExclamationCircleOutlined style={{ color: 'var(--color-error)' }} />
  }

  return (
    <Space direction="vertical" style={{ width: '100%' }} size="small">
      <Button icon={<FolderOpenOutlined />} onClick={openSelectPath} loading={loading} block>
        选择游戏路径
      </Button>
      <Input
        value={settings?.path}
        disabled
        placeholder="请选择 HS2 游戏根目录"
        suffix={<Tooltip title={getStatusText()}>{getStatusIcon()}</Tooltip>}
      />
    </Space>
  )
}
```

**特性**：
- 使用 `usePathSelector` hook 处理路径选择
- 自动验证路径（检查 `HoneySelect2.exe` 是否存在）
- 显示路径状态图标（有效/无效/检查中/未设置）

### 2. 数据分析 (Scan.tsx)

**功能**：扫描本地资源，分析 Mods、场景和角色卡，统计使用次数

**实现流程**：

```
用户点击「开始分析」
    ↓
设置 scanStatus 为 'running'
    ↓
按顺序执行三个分析任务：
  1. 分析 Mods (scanMods)
     - 扫描所有 .zipmod 文件
     - 提取 manifest.xml 中的 GUID、名称、版本
  2. 分析场景 (scanScene)
     - 扫描所有场景 PNG 文件
     - 提取角色名和所需 Mod GUID
  3. 分析角色 (scanFemale)
     - 扫描所有角色卡 PNG 文件
     - 提取角色名和所需 Mod GUID
    ↓
合并使用统计并保存到 Store
    ↓
设置 scanStatus 为 'complete'
```

**代码实现**：

```typescript
// src/renderer/src/components/home/Scan.tsx
export const Scan: FC = () => {
  const { setMods, setUseage } = useModStore()
  const { scanStatus, scanProgress, setScanStatus, setScanProgress } = useTaskStore()

  const { current, info } = scanProgress
  const scanning = scanStatus === 'running'

  // 三个分析步骤
  const steps = useMemo(() => [
    { title: '分析 Mods', description: info.mod },
    { title: '分析场景', description: info.scene },
    { title: '分析角色', description: info.chara }
  ], [info])

  const scan = async () => {
    setScanStatus('running')
    setScanProgress({ current: 0 })

    try {
      // 1. 扫描 Mods
      const mods = await scanMods(
        increaseCurrent,
        (t) => setScanProgress({ info: { ...info, mod: t } })
      )

      // 2. 扫描场景
      const scene = await scanScene(
        increaseCurrent,
        (t) => setScanProgress({ info: { ...info, scene: t } })
      )

      // 3. 扫描角色卡
      const female = await scanFemale(
        increaseCurrent,
        (t) => setScanProgress({ info: { ...info, chara: t } })
      )

      // 合并使用统计
      const mergedUseage = { ...scene, ...female }
      await setMods(mods)
      await setUseage(mergedUseage)

      setScanStatus('complete')
    } catch (error) {
      setScanStatus('error')
    }
  }

  return (
    <Space direction="vertical" style={{ width: '100%' }} size="middle">
      <Button
        type="primary"
        size="large"
        loading={scanning}
        onClick={scan}
        icon={isComplete ? <CheckCircleOutlined /> : <PlayCircleOutlined />}
        block
      >
        {scanning ? '分析中...' : isComplete ? '重新分析' : '开始分析'}
      </Button>

      {(scanning || current >= 0) && (
        <RunningProgress current={current} items={steps} />
      )}
    </Space>
  )
}
```

**特性**：
- 使用 `taskStore` 管理扫描状态（idle/running/complete/error）
- 显示实时进度步骤（分析 Mods → 分析场景 → 分析角色）
- 使用 `RunningProgress` 组件显示进度
- 分析完成后自动保存到 ModStore

### 3. 数据初始化

#### 3.1 更新 Sideload 数据 (SideloaderUpdate.tsx)

**功能**：运行爬虫抓取 BetterRepack 的 Mod 数据库

**数据来源**：`https://sideload.betterrepack.com/download/AISHS2/`

**实现流程**：

```
用户点击「更新数据」
    ↓
调用 window.api.startSideloadUpdate()
    ↓
启动 sideloader.exe 子进程
    ↓
爬取所有 zipmod 文件
    ↓
提取 manifest.xml 中的 GUID
    ↓
生成 result.json（GUID → URL 映射）
    ↓
保存到 userData/result.json
    ↓
通知前端完成
```

**代码实现**：

```typescript
// src/renderer/src/components/home/SideloaderUpdate.tsx
export const SideloaderUpdate: FC = () => {
  const {
    sideloadUpdateStatus,
    sideloadUpdateProgress,
    setSideloadUpdateStatus
  } = useTaskStore()

  const isRunning = sideloadUpdateStatus === 'running'
  const { message: progressMsg, percent } = sideloadUpdateProgress

  const update = async () => {
    setSideloadUpdateStatus('running')
    const result = await window.api.startSideloadUpdate()

    if (result.success) {
      setSideloadUpdateStatus('success')
      message.success('数据更新完成')
    } else {
      setSideloadUpdateStatus('error')
      message.error('更新失败')
    }
  }

  return (
    <div>
      <Button type="primary" loading={isRunning} onClick={update} block>
        {isRunning ? '更新中...' : '更新 Sideload 数据'}
      </Button>
      {isRunning && (
        <>
          <Progress percent={percent} size="small" status="active" />
          <Text type="secondary" style={{ fontSize: 12 }}>{progressMsg}</Text>
        </>
      )}
    </div>
  )
}
```

**生成的数据结构**：

```json
{
  "author.modname.1": "download/AISHS2/Sideloader Modpack/Author/modname.zipmod",
  "another.mod.2": "download/AISHS2/Sideloader Modpack/Another/mod.zipmod"
}
```

#### 3.2 补全缺失 Mods (SideloadInit.tsx)

**功能**：根据角色卡和场景所需的 Mod，自动下载缺失的部分

**实现流程**：

```
用户点击「补全缺失 Mods」
    ↓
1. 获取已安装的 Mods（从 modStore）
    ↓
2. 获取 Sideload 数据（result.json）
    ↓
3. 对比已安装 Mods 和使用统计，找出缺失的 Mods
    ↓
4. 过滤出有下载链接的缺失 Mods
    ↓
5. 批量下载并保存到游戏 mods 目录
```

**代码实现**：

```typescript
// src/renderer/src/components/home/SideloadInit.tsx
export const SideloadInit: FC = () => {
  const { mods, useage } = useModStore()
  const [downloading, setDownloading] = useState(false)
  const [totalCount, setTotalCount] = useState(0)
  const [currentIndex, setCurrentIndex] = useState(0)

  const init = async () => {
    setDownloading(true)
    setCurrentIndex(0)

    // 1. 获取已安装的 Mod GUID 列表
    const installedMods = Object.keys(mods)

    // 2. 获取 Sideload 数据
    const sideloadData = await window.api.initSideload()

    // 3. 计算缺失的 Mods（在使用统计中但不在已安装列表中）
    const neededMods = Object.keys(useage)
    const missingMods = neededMods.filter(guid => !installedMods.includes(guid))

    // 4. 过滤出有下载链接的
    const downloadList = missingMods
      .map(guid => ({ guid, url: sideloadData[guid] }))
      .filter(item => item.url)

    setTotalCount(downloadList.length)

    // 5. 批量下载
    for (let i = 0; i < downloadList.length; i++) {
      const item = downloadList[i]
      setCurrentIndex(i + 1)

      await window.api.startDownload({
        url: item.url,
        fileName: `${item.guid}.zipmod`,
        targetDir: 'mods'
      })
    }

    setDownloading(false)
    message.success(`成功下载 ${downloadList.length} 个 Mod`)
  }

  return (
    <div>
      <Button type="primary" loading={downloading} onClick={init} block>
        {downloading ? `下载中 ${currentIndex}/${totalCount}` : '补全缺失 Mods'}
      </Button>
      {downloading && (
        <Text type="secondary" style={{ fontSize: 12 }}>
          正在下载: {currentIndex} / {totalCount}
        </Text>
      )}
    </div>
  )
}
```

### 4. 快速启动 (GameLauncher.tsx)

**功能**：一键启动游戏或工作室

**实现**：

```typescript
// src/renderer/src/components/home/GameLauncher.tsx
export const GameLauncher: FC = () => {
  const { settings } = useSettingStore()

  const launchGame = async () => {
    if (!settings.path) {
      message.error('请先设置游戏路径')
      return
    }

    try {
      await window.api.launchGame()
      message.success('游戏启动中...')
    } catch (e) {
      message.error('启动失败: ' + e.message)
    }
  }

  const launchStudio = async () => {
    if (!settings.path) {
      message.error('请先设置游戏路径')
      return
    }

    try {
      await window.api.launchStudio()
      message.success('工作室启动中...')
    } catch (e) {
      message.error('启动失败: ' + e.message)
    }
  }

  return (
    <Space direction="vertical" style={{ width: '100%' }}>
      <Button icon={<PlayCircleOutlined />} onClick={launchGame} block>
        启动游戏
      </Button>
      <Button icon={<EditOutlined />} onClick={launchStudio} block>
        启动工作室
      </Button>
    </Space>
  )
}
```

## 状态管理

首页涉及多个 Store：

| Store | 用途 | 关键字段 |
|-------|------|----------|
| `settingStore` | 用户设置 | `path`, `proxy` |
| `modStore` | Mod 数据 | `mods`, `useage` |
| `taskStore` | 任务状态 | `scanStatus`, `scanProgress`, `sideloadUpdateStatus` |

### taskStore 结构

```typescript
// src/renderer/src/store/taskStore.ts
interface TaskState {
  // Scan 任务状态
  scanStatus: 'idle' | 'running' | 'complete' | 'error'
  scanProgress: {
    current: number
    info: {
      mod: string
      scene: string
      chara: string
    }
  }

  // Sideload 更新任务状态
  sideloadUpdateStatus: 'idle' | 'running' | 'success' | 'error'
  sideloadUpdateProgress: {
    message?: string
    percent?: number
  }
}
```

## 注意事项

1. **路径验证** - 设置路径时自动验证是否存在 `HoneySelect2.exe`
2. **扫描顺序** - 按 Mods → 场景 → 角色的顺序分析
3. **代理设置** - Sideloader 和下载器都使用 settingStore 中的代理配置
4. **数据依赖** - 补全缺失 Mods 需要先完成数据分析和 Sideload 数据更新
5. **任务状态** - 使用 taskStore 统一管理长时间运行任务的状态
