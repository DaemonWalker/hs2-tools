# 场景管理功能

## 概述

场景管理功能用于管理 Honey Select 2 游戏中的场景文件（.png），提供场景浏览、搜索、详情查看和智能归档功能。

## 功能特性

### 1. 场景库（Gallery）

以卡片网格形式展示所有场景文件，支持：

- **无限滚动加载** - 使用 ahooks `useInfiniteScroll`，每批加载 24 个场景
- **多维度排序** - 支持 4 种排序方式：
  - 收藏优先（默认）
  - 名称 A-Z
  - 名称 Z-A
  - 路径排序
- **搜索过滤** - 支持按场景名称搜索
- **收藏功能** - 点击心形图标收藏/取消收藏，数据存储在 localStorage
- **详情抽屉** - 点击卡片打开右侧抽屉，显示场景大图、信息和模组依赖

### 2. 智能整理（Organize）

按角色名称自动归档场景文件：

- **任务管理** - 支持创建多个整理任务，按顺序执行
- **角色匹配** - 输入多个角色名称（每行一个），系统会找出包含这些角色的所有场景
- **自动归档** - 将匹配的场景移动到指定的文件夹（自动添加 `hs_tools_` 前缀）
- **进度追踪** - 实时显示扫描、分析、移动各阶段的进度
- **结果统计** - 显示每个任务成功归档的场景数量

## 技术实现

### 核心组件

| 组件 | 路径 | 说明 |
|------|------|------|
| Scenes | `src/renderer/src/pages/Scenes.tsx` | 场景管理主页面 |
| SceneOrganizer | `src/renderer/src/components/scene/SceneOrganizer.tsx` | 智能整理功能组件 |
| SceneDetailDrawer | `src/renderer/src/components/scene/SceneDetailDrawer.tsx` | 场景详情抽屉 |
| CardGrid | `src/renderer/src/components/share/CardGrid.tsx` | 卡片网格列表（场景/角色通用） |

### 状态管理

- **收藏状态** - 使用 localStorage 存储，通过 `useLocalStorageState` hook 管理
- **任务状态** - 组件内部 useState 管理，包含任务列表、执行状态、进度信息

### IPC 通信

| 方法 | 说明 |
|------|------|
| `getAllFiles` | 获取指定目录下的所有文件 |
| `readAllCharaNames` | 读取场景文件中包含的角色名称 |
| `checkTargetDir` | 检查/创建目标文件夹 |
| `moveFile` | 移动文件到指定目录 |
| `readPngPageDataBatch` | 批量读取场景图片和名称数据 |

## 使用流程

### 浏览场景

1. 进入「场景」页面，默认显示「场景库」视图
2. 使用搜索框过滤场景名称
3. 使用排序按钮调整显示顺序
4. 点击场景卡片打开详情抽屉
5. 点击心形图标收藏喜欢的场景

### 整理场景

1. 切换到「智能整理」视图
2. 在左侧输入角色名称（每行一个）
3. 输入目标文件夹名称
4. 点击「添加到任务列表」
5. 可以继续添加更多任务
6. 点击「执行所有任务」或单独执行某个任务
7. 等待任务完成，查看结果统计

## 注意事项

1. **文件夹前缀** - 自动添加 `hs_tools_` 前缀，避免与游戏原有文件夹冲突
2. **任务顺序** - 多个任务按顺序执行，避免文件冲突
3. **重复处理** - 同一文件匹配多个任务时，以第一个匹配的任务为准
4. **路径设置** - 必须先设置游戏路径才能使用场景管理功能
