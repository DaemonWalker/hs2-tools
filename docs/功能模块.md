# 功能模块

应用由 8 个窗口组成：主窗口（首页）常驻，其余 7 个经导航打开（单例，关闭即隐藏保状态）。

## 主窗口（首页）

- **游戏路径**：选择游戏目录，自动校验 `HoneySelect2.exe`（红/绿状态点 + 提示文案）；各功能以路径有效为门控。
- **数据分析**：三阶段扫描（Mod → 场景 → 角色卡），分批 500 带进度；Mod 使用统计合并规则为"角色覆盖场景"。
- **快速启动**：一键启动游戏（`HoneySelect2.exe`）/ 工作室（`StudioNEOV2.exe`）。
- **Sideloader 更新**：运行/停止（停止需确认，停止后不落盘、状态显示"已停止"）；结果落盘 `sideload.json` 真实生效。
- **缺失补全**：列出"被引用但本地缺失且 sideload 库中有"的 Mod，串行批量下载（失败不阻断），结束显示汇总（成功/失败数）。
- **数据概览**：本地 Mod 数、被引用 Mod 数、总引用次数、缺失数；无扫描数据时不显示"已就绪"。

## 角色卡浏览（CharaWindow）

- CardGridControl 虚拟化网格：缩略图、分批加载（每批 24）、滚动加载、收藏（♥）、四种排序（收藏优先/名称 A-Z/名称 Z-A/路径，zh-CN 与浏览器 ICU 行为一致）。
- 搜索框逐键实时过滤（子串匹配）。
- 详情面板：大图、Mod 依赖列表（已拥有/缺少标记）、单项下载、**一键下载缺失**、真实修改时间与文件大小、打开所在文件夹。
- 未设置游戏路径时网格显示引导文案。

## 场景库（SceneWindow）

- 场景网格（同角色卡浏览，16:9 卡片）。
- **智能整理**：按"角色名子串匹配场景卡角色名"创建整理任务；批量执行（进度 0~50 分析 / 50~100 移动）；移动到 `scene/hs_tools_<文件夹名>/`（已整理目录自动排除）；单文件失败记日志并计数，完成文案显示"（N 个失败）"；执行中删除/清空按钮置灰。

## 本地模组（ModsWindow）

- DataGrid 表格：名称、GUID、版本、使用次数；列排序、虚拟化。
- 筛选：所有 / 未使用；统计卡（Mod 数、被引用数、总引用次数）；刷新重扫（防重入）。
- 使用次数匹配大小写不敏感。

## Sideload 数据库（SideloadWindow）

- 浏览内嵌/用户更新的 BetterRepack 全量库（12k+ 条目）：GUID、相对路径、已存在/缺失状态。
- 300ms 防抖搜索（版本号作废旧查询，快速输入不错乱）。
- 缺失条目行内下载（按钮状态与他窗发起的下载实时联动）。

## 下载任务（DownloadWindow）

- 统计栏：活跃数、失败数、总速度。
- 四个 Tab：全部 / 下载中 / 已完成 / 失败（**失败 Tab 仅含 Failed，不含 Cancelled**）。
- 任务项：进度条、速度、剩余时间、取消、重试；全部取消、清除完成（清所有非下载中任务）。
- 窗口关闭不中断下载，重开从任务表重建视图；同名任务重试自动去重行。

## 卡片探索器（CardExplorerWindow）

- 打开单个 PNG 卡片：人物卡 / 场景卡两种布局。
- 显示大图、名称、描述、Mod 依赖（含缺失标记）、场景人物列表；无图/空列表均有占位文案；解析失败显示错误页。

## 系统设置（SettingsWindow）

- 代理表单：地址（http/https/socks5，留空直连）、用户名、密码；非法地址红字提示。
- 防休眠开关（`SetThreadExecutionState`），应用启动时按配置恢复。
- 改动即时生效并防抖持久化。
