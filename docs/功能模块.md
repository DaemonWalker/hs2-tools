# 功能模块

应用由 8 个窗口组成：主窗口（首页）常驻，其余 7 个经导航打开（单例，关闭即隐藏保状态）。

## 主窗口（首页）

- **游戏切换器**：顶部按 `GameProfiles.All` 列出支持的游戏（HS2 / 恋活 KK / 恋活 Sunshine KKS），当前游戏高亮且禁用；切换后标题区文案随当前游戏 `DisplayName` 变化，其他窗口自动按新游戏目录重扫；扫描/爬虫运行中禁止切换。
- **游戏路径**：选择当前游戏目录，按该游戏 exe（如 `HoneySelect2.exe` / `Koikatu.exe` / `KoikatsuSunshine.exe`）自动校验（红/绿状态点 + 提示文案）；各游戏路径独立保存，各功能以路径有效为门控。
- **数据分析**：三阶段扫描（Mod → 场景 → 角色卡），分批 500 带进度；Mod 阶段顺带扫描 `unusedmods/`（单独成表，不进 LocalMods），数据概览"本地 Mods"后括号显示未使用数；分析完成后若发现 unusedmods 里有被卡片引用且 mods 中没有同 GUID 的 Mod，弹确认框，确认后平移回 mods 根目录（同名加 _2/_3 后缀）并补录 LocalMods。Mod 使用统计合并规则为"角色覆盖场景"；统计数据按游戏隔离。分析结果同时持久化为 Mods 窗口去重/整理的数据源缓存（完整 zipmod 条目含重复 guid 且覆盖 unusedmods、人物/场景分卡引用集、卡片 KKEx 命中的 shader 名、完成时点）；shader 命中检测与读卡同一趟完成，不增加磁盘读取。
- **快速启动**：一键启动当前游戏 / 工作室（exe 名取当前游戏档案）。
- **Sideloader 更新**：运行/停止（停止需确认，停止后不落盘、状态显示"已停止"）；爬虫起点取当前游戏档案（KK/KKS 从 KKEC 根目录递归下钻全部子 Modpack），结果按数据源落盘 `sideload-{数据源}.json` 真实生效（KK/KKS 共享 kkec 库）。
- **缺失补全**：列出"被引用但本地缺失且 sideload 库中有"的 Mod，串行批量下载（失败不阻断，下载 base URL 按当前游戏），结束显示汇总（成功/失败数）。
- **数据概览**：本地 Mod 数、被引用 Mod 数、总引用次数、缺失数；无扫描数据时不显示"已就绪"。

## 角色卡浏览（CharaWindow）

- CardGridControl 虚拟化网格：缩略图、分批加载（每批 24）、滚动加载、收藏（♥）、四种排序（收藏优先/名称 A-Z/名称 Z-A/路径，zh-CN 与浏览器 ICU 行为一致）。
- 搜索框逐键实时过滤（子串匹配）。
- 详情面板：大图、Mod 依赖列表（已拥有/缺少标记）、单项下载、**一键下载缺失**、真实修改时间与文件大小、打开所在文件夹。
- 卡片解析按卡头标记自动识别游戏格式（HS2 与 KK/KKS 卡片都能解析，角色名按各游戏字段规则拼接）。
- 切换游戏后自动按新游戏角色卡目录重扫；未设置游戏路径时网格显示引导文案。

## 场景库（SceneWindow）

- 场景网格（同角色卡浏览，16:9 卡片）；切换游戏后自动按新游戏场景目录重扫。
- **智能整理**：按"角色名子串匹配场景卡角色名"创建整理任务；批量执行（进度 0~50 分析 / 50~100 移动）；移动到 `scene/hs_tools_<文件夹名>/`（已整理目录自动排除）；单文件失败记日志并计数，完成文案显示"（N 个失败）"；执行中删除/清空按钮置灰。

## 本地模组（ModsWindow）

- DataGrid 表格：名称、GUID、版本、使用次数；列排序、虚拟化。
- 筛选：所有 / 未使用；统计卡（Mod 数、被引用数、总引用次数）；刷新重扫（防重入）。
- 使用次数匹配大小写不敏感。
- **去重 Mods**：以「开始分析」持久化的完整条目缓存为数据源（不重扫磁盘；从未分析过提示先分析，确认文案标注缓存时点），只针对 mods 目录条目；相同 GUID 按"版本号高 → 体积大 → 修改日期新"裁决保留一个（全平按路径词典序取确定结果）；弹确认框后落选文件移动到游戏根目录 `duplicatemods/`（重名自动加 `_2` 后缀，下载目录内文件跳过；缓存时点后已消失的文件按存在性校验跳过），LocalMods 更新为各 GUID 最优、条目缓存同步移除落选者；与刷新互斥防重入。普通扫描遇重复 GUID 也按同一裁决规则取最优。
- **整理 Mods**：同样走「开始分析」缓存（不重扫磁盘）：完整 zipmod 条目（覆盖 mods/unusedmods，按路径排除下载目录与 `mods/scenemods/`）+ 分卡（人物/场景）引用集 + 卡片 shader 命中名单（均随分析持久化在 settings.json）；先按去重规则跨两目录裁决同 GUID 重复，落选（含 unusedmods 里的）→ 游戏根目录 `duplicatemods/`；再对赢家分类：两卡都未引用 → `unusedmods/` 平铺（已在 unusedmods 的原地不动）；被引用且有扫描记录、GUID 在站点索引 → `mods/<站点相对目录>/`（含从 unusedmods 移回，无目录部分进 mods 根目录；站点相对路径含 `..` 或 rooted 视为不在索引，ErrorLog 留痕）；**站点目录优先于 scenemods** —— 仅场景引用且在索引的也进站点目录，仅场景不在索引 → `mods/scenemods/`；人物卡引用不在索引 → 在 unusedmods 的移回 mods 根目录、在 mods 的原地不动。**shader 使用豁免**：卡片不按 GUID 引用 shader 包，但会把用到的 shader 名明文留在 KKEx（Material Editor 数据）里——分析时以各 mod manifest 的 `<MaterialEditor><Shader Name="..."/>` 声明为候选随读卡同一趟做内容级匹配并持久化命中名单，提供了被使用 shader 的 mod 按"人物卡引用"同口径处理（不搬 unusedmods；已在 unusedmods 的移回），未被任何卡片使用的 shader 包照常判未使用。弹确认框列出各类数量（为 0 省略）后执行，文件消失/移动失败记日志跳过不中断，LocalMods 与条目缓存以最终落点写回（仍在 mods 目录下的赢家才收录进 LocalMods；移动失败的落选者保留在条目缓存供下次整理）；与刷新/去重互斥防重入。

## Sideload 数据库（SideloadWindow）

- 浏览 BetterRepack 全量库（12k+ 条目）：GUID、相对路径、已存在/缺失状态；按数据源分库（HS2 独占 hs2 库，KK/KKS 共享 kkec 库），随当前游戏切换；kkec 无内嵌库，需先在主窗口运行一次爬虫更新。
- 上次扫描时间与结果持久化到独立 meta 文件 `sideload-{数据源}.meta.json`（成功结束 / 已停止 / 异常终止，含发现数量或错误原因），统计三卡下方实时显示「上次扫描」；整理 Mods 的站点目录归位以 meta 存在为启用前提。
- 300ms 防抖搜索（版本号作废旧查询，快速输入不错乱）。
- 缺失条目行内下载（按钮状态与他窗发起的下载实时联动）。

## 下载任务（DownloadWindow）

- 统计栏：活跃数、失败数、总速度。
- 四个 Tab：全部 / 下载中 / 已完成 / 失败（**失败 Tab 仅含 Failed，不含 Cancelled**）。
- 任务项：进度条、速度、剩余时间、取消、重试；全部取消、清除完成（清所有非下载中任务）。
- 窗口关闭不中断下载，重开从任务表重建视图；同名任务重试自动去重行。

## 卡片探索器（CardExplorerWindow）

- 打开单个 PNG 卡片：人物卡 / 场景卡两种布局。
- 显示大图、名称、描述、Mod 依赖（含缺失标记）、场景人物列表；无图/空列表均有占位文案；解析失败显示错误页。

## 系统设置（SettingsWindow）

- 代理表单：地址（http/https/socks5，留空直连）、用户名、密码；非法地址红字提示。
- 防休眠开关（`SetThreadExecutionState`），应用启动时按配置恢复。
- 改动即时生效并防抖持久化。
