# 代码规范

HS2-Tools 项目代码规范分为两部分：

| 规范 | 说明 |
|------|------|
| [Go 代码规范](./Go代码规范.md) | Go 工具开发规范，强调函数式编程风格 |
| [前端代码规范](./前端代码规范.md) | React + TypeScript 前端规范 |

## 快速参考

### 命名规范对比

| 类型 | Go | TypeScript |
|------|-----|-----------|
| 文件 | `snake_case.go` | `camelCase.ts` / `PascalCase.tsx` |
| 函数 | `PascalCase`（导出）/ `camelCase`（内部） | `camelCase` |
| 变量 | `camelCase` / 短命名 | `camelCase` |
| 常量 | `PascalCase` | `SCREAMING_SNAKE_CASE` |

### 核心理念对比

| Go | TypeScript |
|----|-----------|
| 函数式优先 | 组件化 |
| 数据与逻辑分离 | 封装与抽象 |
| 避免过度接口设计 | 接口定义 Props |
| 错误作为值返回 | try-catch / Promise |
